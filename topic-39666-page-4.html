Fixed:

  • Fix: TreeView SelChanged not firing in Unicode mode (source\classes\window.prg,
    source\ceclasses\window.prg):
    When FW_SetUnicode(.T.) is active, the TreeView control sends TVN_SELCHANGEDW
    (-456) instead of TVN_SELCHANGEDA (-402). The Notify() handler only matched
    the ANSI code, so bChanged callbacks never fired in Unicode mode. Fixed: add
    TVN_SELCHANGEDW to the case condition alongside TVN_SELCHANGEDA.
Code: Select all Collapse
 #define TVN_SELCHANGEDA  -402  // CommCtrl TreeView notification
+#define TVN_SELCHANGEDW  -456  // CommCtrl TreeView notification (Unicode)

-         case nCode == 103 .or. nCode == TVN_SELCHANGEDA  // TreeView item selected
+         case nCode == 103 .or. nCode == TVN_SELCHANGEDA .or. nCode == TVN_SELCHANGEDW  // TreeView item selected
