#include "FiveWin.ch"

FUNCTION ConectaxH()
   LOCAL oCn  := NIL
   LOCAL cMsg := ""
   LOCAL oErr := NIL

   TRY
      FWCONNECT oCn ;
         HOST     GetEnv( "DB_HOST" )    ;
         USER     GetEnv( "DB_USER" )    ;
         PASSWORD GetEnv( "DB_PASS" )    ;
         PORT     Val( GetEnv( "DB_PORT" ) ) ;
         CHARSET  "utf8mb4"              ;
         DATABASE GetEnv( "DB_NAME" )

  IF oCn == NIL .OR. !oCn:IsConnected()
     MsgStop( "Não foi possível conectar ao banco de dados.", "Erro de Conexão" )
     RETURN NIL
  ENDIF

  // Só exibe erros detalhados em ambiente de desenvolvimento
  oCn:lShowErrors := ( Upper( GetEnv( "FW_MODE" ) ) == "DEV" )

   CATCH oErr
      cMsg := "Erro crítico ao acionar o driver de conexão!" + CRLF + ;
              "Detalhes: " + oErr:Description
      MsgStop( cMsg, "Erro de Sistema" )
      RETURN NIL
   END

RETURN oCn

Estimado Luis Alfonso:

Gracias por la aclaración. Que el TRY no capture nada y que el programa se cierre tras unos 2 segundos nos dice algo útil: TRY solo recoge errores de Harbour. Si el proceso termina sin mensaje, el cierre ocurre fuera de ese control, y primero hay que localizar en qué punto exacto sucede.

La mención a la versión 5.0 de MySQL es solo una hipótesis; hoy no tenemos evidencia de que sea la causa. Es un dato útil, pero no concluyente.

Los ejemplos MariaDB de FWH (samples/misc/maria07.prg) comprueban si la conexión devolvió nil, activan el registro de errores y, tras ejecutar, consultan el error y lo muestran. Prueba este programa mínimo, en una copia, con el mismo EXE y librerías que ahora fallan:

Code: Select all Collapse
#include "FiveWin.ch"

FUNCTION Main()

   LOCAL oCn

   MsgInfo( "1 - antes de conectar" )

   FWCONNECT oCn HOST "localhost" USER "usuario" PASSWORD "clave" DATABASE "basededatos"

   if oCn == nil
      MsgStop( "2 - Connect Fail" )
      return nil
   endif

   oCn:lLogErr := .t.
   MsgInfo( "3 - conectado" )

   oCn:Execute( "SELECT VERSION()" )
   if oCn:nError != 0
      oCn:ShowError()
   else
      MsgInfo( "4 - consulta correcta" )
   endif

   oCn:Close()

RETURN nil

Dime cuál es el último mensaje que llegas a ver (1, 2, 3 o 4) y si aparece algo en ShowError. Además necesito: la versión del servidor MySQL, que puedes obtener con otro cliente (HeidiSQL, por ejemplo) ejecutando SELECT VERSION(); y qué DLL de MySQL/MariaDB hay junto a tu EXE (nombre y tamaño).

Usa usuario y clave de pruebas; no publiques credenciales reales.
