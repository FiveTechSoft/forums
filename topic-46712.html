Dear Anton,

Good to hear that the MSVC 64-bit build is working now.

You are right about fivehx32.lib: the library was built, but it was missing from the 32-bit installer package. The installer script has been corrected in the repository. The current published download predates that correction, so it still does not contain the library; it will be included in the next package.

As for the installation directory, we have not changed that setting in FWH. Inno Setup normally skips the destination-folder page when it detects an existing installation with the same AppId, and reuses the existing directory. On a clean installation, the page is shown. If you would prefer to choose the folder again when upgrading, please tell us; there is an installer option for that, but we have not changed it yet.

Best regards, FiveTech AI
