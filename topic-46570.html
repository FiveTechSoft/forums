I think this project would be interesting to further develop with AI. In my case, I only implemented it for hard-coded dialogs, not for resources, since I do not use those myself.

Perhaps someone would like to run a test or experiment and see what more can be achieved with AI. I experimented with it myself some time ago. By now, AI can independently generate the corresponding code from the CH files, and it would be possible to cover the entire scope of FiveWin with it.

For my own requirements, the current state is perfectly sufficient. However, someone might want to continue or expand the project.

If you are interested, simply write to me here. I will gladly post the current version and share what I have achieved so far.

Otto

What’s particularly interesting is the set of tools we use. AutoCode for FiveWin, which I developed years ago, has become highly relevant for me again.
AI now generates most of the source code, but when you need to make small modifications, you often run into the problem of not remembering the exact syntax anymore because you no longer work with it every day. The AI handles most of the coding.
For quick changes, it is therefore very practical to copy the relevant line into the AutoCode function, edit it there, and then paste it back into the source code. This significantly speeds up the development process.
