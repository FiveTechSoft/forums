Huso horario en Windows: desfase, horario de verano y conversión UTC <-> hora local

La conversión entre UTC y hora local ya ha aparecido en estos foros dentro de ejemplos de fechas de archivo (por ejemplo el programa FileTimes del tema "Fecha/Hora de creación"), donde la conversión es un medio y no el tema. Este ejemplo se centra en el huso horario en sí: qué información devuelve GetTimeZoneInformation, cómo se interpretan sus campos y cómo convertir entre UTC y hora local con SystemTimeToTzSpecificLocalTime y TzSpecificLocalTimeToSystemTime, con casos medidos y los límites que documenta Microsoft.

Qué hace el programa

Al pulsar "Consultar ahora" muestra, del equipo donde se ejecuta:

  • Nombres localizados del horario estándar y del horario de verano (vienen en Unicode y se convierten a ANSI con WideCharToMultiByte, comprobando el error).
  • Desfase base en minutos y su equivalencia práctica. La fórmula documentada es UTC = hora local + desfase, es decir, hora local = UTC - desfase.
  • Desfases adicionales de horario estándar y de verano (se suman al base; el de verano suele ser -60).
  • Fechas de cambio de horario, en la notación documentada: wYear = 0 para una regla anual, wDayOfWeek de 0 (domingo) a 6, wDay de 1 a 5 donde 5 significa "última ocurrencia", y wMonth = 0 cuando ese cambio no existe.
  • El régimen actual según el valor de retorno: 0 = el huso no aplica horario de verano, 1 = horario estándar en curso, 2 = horario de verano en curso.
  • La hora UTC actual (GetSystemTime) convertida a local con SystemTimeToTzSpecificLocalTime, y esa local reconvertida a UTC con TzSpecificLocalTimeToSystemTime para comprobar la ida y vuelta.
  • Dos fechas fijas del año en curso (15 de enero y 15 de julio a las 12:00 UTC) convertidas a local, para ver el efecto del horario de verano.

Resultados medidos

Programa compilado con Harbour 3.2.1dev y FWH 26.10 (FiveHG64), ejecutado en Wine 11.19 (sin Windows nativo), 20 de noviembre de 2026, con el huso Europe/Madrid del equipo de la prueba:

  • Nombres: "Romance Standard Time" / "Romance Daylight Time". Ojo: son los nombres que devuelve este Wine, que los da en inglés; Microsoft documenta que vienen localizados según el idioma de la interfaz, así que en un Windows con interfaz en español saldrán en español. No son los nombres de un Windows español.
  • Desfase base: -60 minutos, es decir, hora local = UTC+01:00 en horario estándar.
  • Desfases estándar / verano: 0 / -60.
  • Paso a horario estándar: mes 10, domingo, última ocurrencia, 03:00. Paso a horario de verano: mes 3, domingo, última ocurrencia, 02:00.
  • Régimen actual: 1 (horario estándar en curso).
  • Hora UTC 20/11/2026 11:02:44 convertida a local: 12:02:44. La reconversión a UTC recuperó la hora original (coinciden los 7 campos, de año a segundo).
  • 15/01/2026 12:00 UTC -> 13:00:00 local. 15/07/2026 12:00 UTC -> 14:00:00 local: una hora más en verano por el DaylightBias de -60.

Estos valores son los medidos en ese entorno y fecha. El régimen y las fechas de cambio corresponden al huso Europe/Madrid; en otro equipo variarán, como el propio ejemplo advierte. No afirmamos que Wine reproduzca todos los detalles de Windows nativo.

Límites que documenta Microsoft

  • Cerca de los cambios de horario hay horas locales ambiguas (ocurren dos veces) o inexistentes (no ocurren): al convertirlas a UTC no hay un resultado "correcto" garantizado.
  • SystemTimeToTzSpecificLocalTime puede calcular mal cuando la hora UTC y la local calculada caen en años distintos y el huso usa desfases diferentes en ambos años.
  • Para husos cuyas reglas de horario de verano cambian de un año a otro, Microsoft indica GetDynamicTimeZoneInformation o GetTimeZoneInformationForYear en lugar de GetTimeZoneInformation.

Requisitos

Mínimo documentado de estas APIs: Windows 2000. Todas viven en kernel32, que cualquier aplicación Windows ya enlaza habitualmente, así que usarlas no exige añadir ninguna biblioteca específica. Es el mínimo documentado de estas APIs, no una garantía de que toda la aplicación de ejemplo sea compatible con Windows 2000.

El código íntegro y las capturas continúan en las respuestas siguientes de este mismo tema.

//----------------------------------------------------------------------------//
// HUSOLOCAL.PRG (v2)
// v2: correcciones de compilacion - llamada WideCharToMultiByte en
// una sola linea (el C no admite continuaciones ";"), #include
// hbapiitm.h para hb_itemArrayNew/hb_itemRelease/hb_itemReturnRelease
// y helper F02 en lugar de hb_sprintf (no disponible en Harbour 3.2)
// Huso horario: desfase, horario de verano y conversion UTC <-> local
// GetTimeZoneInformation + SystemTimeToTzSpecificLocalTime +
// TzSpecificLocalTimeToSystemTime
// Ejemplo didactico FiveWin (FWH) + Harbour
//
// Que muestra:
//   - GetTimeZoneInformation devuelve la configuracion del huso
//     activo: desfase base, desfases de estandar y verano, nombres
//     localizados de ambos horarios y las fechas de cambio
//     (doc. Microsoft)
//   - La formula documentada: UTC = hora local + desfase, con el
//     desfase en minutos; durante el horario de verano se suma
//     ademas DaylightBias (habitualmente -60)
//   - El valor de retorno dice en que regimen esta el sistema:
//     0 = el huso no usa horario de verano, 1 = horario estandar,
//     2 = horario de verano (TIME_ZONE_ID_UNKNOWN / STANDARD /
//     DAYLIGHT; doc. Microsoft)
//   - Las fechas de cambio vienen en notacion "ocurrencia del dia de
//     la semana": wYear = 0 (regla anual), wDayOfWeek 0..6
//     (domingo..sabado), wDay 1..5 donde 5 = ultima ocurrencia del
//     mes; wMonth = 0 significa que ese cambio no existe
//     (doc. Microsoft)
//   - SystemTimeToTzSpecificLocalTime convierte una hora UTC a la
//     hora local correspondiente aplicando el horario de verano que
//     corresponda a esa fecha; con el primer parametro en NULL usa
//     el huso activo (doc. Microsoft)
//   - TzSpecificLocalTimeToSystemTime hace la conversion inversa;
//     Microsoft advierte que cerca de los cambios de horario hay
//     horas locales ambiguas o inexistentes y que la conversion de
//     fechas a uno y otro lado de un cambio de ano puede salir mal
//     si el huso cambia de desfase entre anos (doc. Microsoft)
//
// La demo convierte dos fechas fijas (15 de enero y 15 de julio a
// las 12:00 UTC del ano en curso) para ver el efecto del horario de
// verano, y una ida y vuelta UTC -> local -> UTC con la hora actual
// para comprobar que el sistema recupera la hora original.
//
// Las conversiones se hacen con el huso activo del equipo; los
// valores mostrados son siempre los medidos en el equipo que ejecuta
// el programa.
//
// Minimo documentado de estas APIs: Windows 2000 (doc. Microsoft de
// GetTimeZoneInformation y SystemTimeToTzSpecificLocalTime). Ambas
// viven en kernel32: usarlas no anade ninguna biblioteca.
//
// Los nombres de horario vienen en Unicode (WCHAR) localizados segun
// el idioma de la interfaz de usuario; aqui se convierten a ANSI
// (CP_ACP) con WideCharToMultiByte, comprobando su error, coherente
// con una aplicacion Harbour ANSI.
//
// Comportamiento ante errores:
//   - Cada fila muestra su resultado real; si una API falla, la fila
//     muestra el codigo de GetLastError correspondiente
//   - Al pulsar de nuevo se limpian todas las filas: nada de valores
//     de la ejecucion anterior
//   - La ida y vuelta solo dice "coincide" cuando los 7 campos
//     (ano..segundo) son identicos
//
// Documentacion de Microsoft:
//   https://learn.microsoft.com/en-us/windows/win32/api/timezoneapi/nf-timezoneapi-gettimezoneinformation
//   https://learn.microsoft.com/en-us/windows/win32/api/timezoneapi/ns-timezoneapi-time_zone_information
//   https://learn.microsoft.com/en-us/windows/win32/api/timezoneapi/nf-timezoneapi-systemtimetotzspecificlocaltime
//   https://learn.microsoft.com/en-us/windows/win32/api/timezoneapi/nf-timezoneapi-tzspecificlocaltimetosystemtime
//----------------------------------------------------------------------------//

//----------------------------------------------------------------------------//

static function BtnConsulta()

   local aDatos, cStd, cDay, aUtc, aLoc, aVuelta, aDemo1, aDemo2
   local lTodoOk := .t.
   local lVuelta := .f.
   local i

   // Limpiar resultados de la ejecucion anterior
   oSayStd:SetText( "" )
   oSayDay:SetText( "" )
   oSayBias:SetText( "" )
   oSayBiasSD:SetText( "" )
   oSayPasoStd:SetText( "" )
   oSayPasoDay:SetText( "" )
   oSayRegimen:SetText( "" )
   oSayUtc:SetText( "" )
   oSayLocal:SetText( "" )
   oSayVuelta:SetText( "" )
   oSayDemo1:SetText( "" )
   oSayDemo2:SetText( "" )
   oSayEstado:SetText( "Consultando..." )

   // Datos del huso activo
   aDatos := TZ_Datos()

   if aDatos == NIL
      oSayRegimen:SetText( TextoError() )
      oSayEstado:SetText( "Fallo GetTimeZoneInformation; no se puede continuar" )
      return nil
   endif

   oSayRegimen:SetText( DescRegimen( aDatos[ 1 ] ) )
   oSayBias:SetText( DescBias( aDatos[ 2 ] ) )
   oSayBiasSD:SetText( AllTrim( Str( aDatos[ 3 ] ) ) + " / " + ;
                       AllTrim( Str( aDatos[ 4 ] ) ) + " (min; se suman al base)" )
   oSayPasoStd:SetText( DescPaso( aDatos[ 5 ] ) )
   oSayPasoDay:SetText( DescPaso( aDatos[ 6 ] ) )

   // Nombres localizados (conversion Unicode -> ANSI comprobada)
   cStd := TZ_Nombre( 0 )
   cDay := TZ_Nombre( 1 )

   if cStd == NIL
      oSayStd:SetText( TextoError() )
      lTodoOk := .f.
   else
      oSayStd:SetText( iif( Empty( cStd ), "(vacio)", cStd ) )
   endif

   if cDay == NIL
      oSayDay:SetText( TextoError() )
      lTodoOk := .f.
   else
      oSayDay:SetText( iif( Empty( cDay ), "(vacio)", cDay ) )
   endif

   // Hora UTC actual y conversion a local
   aUtc := TZ_UtcAhora()
   oSayUtc:SetText( FmtDT( aUtc ) + " UTC" )

   aLoc := TZ_UtcALocal( aUtc[ 1 ], aUtc[ 2 ], aUtc[ 4 ], ;
                         aUtc[ 5 ], aUtc[ 6 ], aUtc[ 7 ] )

   if aLoc == NIL
      oSayLocal:SetText( TextoError() )
      oSayVuelta:SetText( "(no se puede hacer sin la hora local)" )
      lTodoOk := .f.
   else
      oSayLocal:SetText( FmtDT( aLoc ) + " local" )

  // Ida y vuelta: local -> UTC y comparar con la original
  aVuelta := TZ_LocalAUtc( aLoc[ 1 ], aLoc[ 2 ], aLoc[ 4 ], ;
                           aLoc[ 5 ], aLoc[ 6 ], aLoc[ 7 ] )

  if aVuelta == NIL
     oSayVuelta:SetText( TextoError() )
     lTodoOk := .f.
  else
     lVuelta := .t.
     for i := 1 to 7
        if aVuelta[ i ] != aUtc[ i ]
           lVuelta := .f.
           exit
        endif
     next
     oSayVuelta:SetText( FmtDT( aVuelta ) + " UTC " + ;
        iif( lVuelta, "(coincide)", "(NO coincide)" ) )
     if ! lVuelta
        lTodoOk := .f.
     endif
  endif
   endif

   // Dos fechas fijas del ano en curso: invierno y verano
   aDemo1 := TZ_UtcALocal( aUtc[ 1 ], 1, 15, 12, 0, 0 )
   aDemo2 := TZ_UtcALocal( aUtc[ 1 ], 7, 15, 12, 0, 0 )

   if aDemo1 == NIL
      oSayDemo1:SetText( TextoError() )
      lTodoOk := .f.
   else
      oSayDemo1:SetText( FmtDT( aDemo1 ) + " local" )
   endif

   if aDemo2 == NIL
      oSayDemo2:SetText( TextoError() )
      lTodoOk := .f.
   else
      oSayDemo2:SetText( FmtDT( aDemo2 ) + " local" )
   endif

   // Estado final segun el resultado real de cada paso
   if lTodoOk
      oSayEstado:SetText( "Consulta completada sin errores" )
   else
      oSayEstado:SetText( "Consulta con errores: el detalle real esta en cada fila" )
   endif

return nil

//----------------------------------------------------------------------------//

static function TextoError()

return "(error " + AllTrim( Str( TZ_LastError() ) ) + ")"

//----------------------------------------------------------------------------//
// Descripcion del regimen actual segun el valor de retorno
// documentado de GetTimeZoneInformation

static function DescRegimen( nId )

   local c

   do case
      case nId == 0
         c := "0: el huso no aplica horario de verano"
      case nId == 1
         c := "1: horario estandar en curso"
      case nId == 2
         c := "2: horario de verano en curso"
      otherwise
         c := AllTrim( Str( nId ) ) + " (valor no documentado)"
   endcase

return c

//----------------------------------------------------------------------------//
// Formula documentada: UTC = hora local + desfase, luego
// hora local = UTC - desfase. Se muestra el desfase y su
// equivalencia como diferencia con UTC.

static function DescBias( nBias )

   local nOff := - nBias
   local cSig := iif( nOff >= 0, "+", "-" )
   local nAbs := Abs( nOff )

return AllTrim( Str( nBias ) ) + " (local = UTC" + cSig + ;
       F02( Int( nAbs / 60 ) ) + ":" + F02( nAbs % 60 ) + ")"

//----------------------------------------------------------------------------//
// Notacion documentada de las fechas de cambio: wYear = 0 (regla
// anual) u otro valor (fecha absoluta de una sola vez); wDayOfWeek
// 0..6 (domingo..sabado); wDay 1..5, donde 5 = ultima ocurrencia;
// wMonth = 0 significa que ese cambio no existe.

static function DescPaso( aFecha )

   local aDow := { "domingo", "lunes", "martes", "miercoles", ;
                   "jueves", "viernes", "sabado" }
   local c := ""

   if aFecha[ 2 ] == 0
      return "sin cambio programado (mes 0)"
   endif

   if aFecha[ 1 ] != 0
      c := "fecha absoluta " + AllTrim( Str( aFecha[ 1 ] ) ) + ", "
   endif

   c += "mes " + AllTrim( Str( aFecha[ 2 ] ) ) + ", " + ;
        aDow[ aFecha[ 3 ] + 1 ] + ", ocurrencia " + ;
        AllTrim( Str( aFecha[ 4 ] ) ) + ;
        iif( aFecha[ 4 ] == 5, " (ultima)", "" ) + ", " + ;
        F02( aFecha[ 5 ] ) + ":" + F02( aFecha[ 6 ] )

return c

//----------------------------------------------------------------------------//
// aSt es { wYear, wMonth, wDayOfWeek, wDay, wHour, wMinute,
// wSecond, wMilliseconds }

static function FmtDT( aSt )

return F02( aSt[ 4 ] ) + "/" + F02( aSt[ 2 ] ) + "/" + AllTrim( Str( aSt[ 1 ] ) ) + ;
       " " + F02( aSt[ 5 ] ) + ":" + F02( aSt[ 6 ] ) + ":" + F02( aSt[ 7 ] )

//----------------------------------------------------------------------------//
// Dos digitos con cero a la izquierda (sustituye a hb_sprintf %02d)

static function F02( n )

return Right( "0" + AllTrim( Str( Int( n ) ) ), 2 )

//----------------------------------------------------------------------------//

#pragma BEGINDUMP

#include <windows.h>
#include "hbapi.h"
#include "hbapiitm.h"

// Ultimo GetLastError() de las TZ_*
static DWORD s_dwLastError = 0;

// Copia los 8 campos de un SYSTEMTIME a un array Harbour:
// { wYear, wMonth, wDayOfWeek, wDay, wHour, wMinute, wSecond, wMilli }
static PHB_ITEM StArray( const SYSTEMTIME * pst )
{
   PHB_ITEM pA = hb_itemArrayNew( 8 );

   hb_arraySetNL( pA, 1, ( long ) pst->wYear );
   hb_arraySetNL( pA, 2, ( long ) pst->wMonth );
   hb_arraySetNL( pA, 3, ( long ) pst->wDayOfWeek );
   hb_arraySetNL( pA, 4, ( long ) pst->wDay );
   hb_arraySetNL( pA, 5, ( long ) pst->wHour );
   hb_arraySetNL( pA, 6, ( long ) pst->wMinute );
   hb_arraySetNL( pA, 7, ( long ) pst->wSecond );
   hb_arraySetNL( pA, 8, ( long ) pst->wMilliseconds );

   return pA;
}

// Rellena un SYSTEMTIME con los campos numericos de Harbour
// (ano, mes, dia, hora, minuto, segundo); wDayOfWeek no lo usan
// estas APIs y queda a 0.
static void RellenaST( SYSTEMTIME * pst )
{
   memset( pst, 0, sizeof( SYSTEMTIME ) );
   pst->wYear   = ( WORD ) hb_parni( 1 );
   pst->wMonth  = ( WORD ) hb_parni( 2 );
   pst->wDay    = ( WORD ) hb_parni( 3 );
   pst->wHour   = ( WORD ) hb_parni( 4 );
   pst->wMinute = ( WORD ) hb_parni( 5 );
   pst->wSecond = ( WORD ) hb_parni( 6 );
}

// TZ_Datos() -> { nRegimen, nBias, nStandardBias, nDaylightBias,
//                 aStandardDate, aDaylightDate } o NIL
// nRegimen es el valor de retorno documentado de
// GetTimeZoneInformation (0/1/2); NIL con TZ_LastError() si falla.
HB_FUNC( TZ_DATOS )
{
   TIME_ZONE_INFORMATION tzi;
   DWORD dwId = GetTimeZoneInformation( &tzi );
   PHB_ITEM pR, pStd, pDay;

   if( dwId == TIME_ZONE_ID_INVALID )
   {
      s_dwLastError = GetLastError();
      hb_ret();   // NIL
      return;
   }

   pR = hb_itemArrayNew( 6 );
   hb_arraySetNL( pR, 1, ( long ) dwId );
   hb_arraySetNL( pR, 2, ( long ) tzi.Bias );
   hb_arraySetNL( pR, 3, ( long ) tzi.StandardBias );
   hb_arraySetNL( pR, 4, ( long ) tzi.DaylightBias );

   pStd = StArray( &tzi.StandardDate );
   hb_arraySet( pR, 5, pStd );
   hb_itemRelease( pStd );

   pDay = StArray( &tzi.DaylightDate );
   hb_arraySet( pR, 6, pDay );
   hb_itemRelease( pDay );

   hb_itemReturnRelease( pR );
   s_dwLastError = 0;
}

// TZ_Nombre( nCual ) -> cNombre o NIL
// nCual 0 = horario estandar, 1 = horario de verano. Los nombres
// vienen en Unicode localizados segun el idioma de la interfaz;
// se convierten a ANSI comprobando el error de la conversion.
HB_FUNC( TZ_NOMBRE )
{
   TIME_ZONE_INFORMATION tzi;
   const WCHAR * pwsz;
   char szBuf[ 128 ];
   int nRes;

   if( GetTimeZoneInformation( &tzi ) == TIME_ZONE_ID_INVALID )
   {
      s_dwLastError = GetLastError();
      hb_ret();   // NIL
      return;
   }

   pwsz = ( hb_parni( 1 ) == 1 ) ? tzi.DaylightName : tzi.StandardName;

   nRes = WideCharToMultiByte( CP_ACP, 0, pwsz, -1, szBuf, ( int ) sizeof( szBuf ), NULL, NULL );
   if( nRes == 0 )
   {
      s_dwLastError = GetLastError();
      hb_ret();   // NIL
      return;
   }

   hb_retc( szBuf );
   s_dwLastError = 0;
}

// TZ_UtcAhora() -> aSt con la hora UTC actual (GetSystemTime no
// tiene valor de retorno ni modo de fallo documentado)
HB_FUNC( TZ_UTCAHORA )
{
   SYSTEMTIME st;
   PHB_ITEM pA;

   GetSystemTime( &st );
   pA = StArray( &st );
   hb_itemReturnRelease( pA );
}

// TZ_UtcALocal( nAno, nMes, nDia, nHora, nMin, nSeg ) -> aSt o NIL
// Convierte una hora UTC a la hora local del huso activo (primer
// parametro NULL), aplicando el horario de verano que corresponda
// a esa fecha (doc. Microsoft).
HB_FUNC( TZ_UTCALOCAL )
{
   SYSTEMTIME stU, stL;
   PHB_ITEM pA;

   RellenaST( &stU );

   if( ! SystemTimeToTzSpecificLocalTime( NULL, &stU, &stL ) )
   {
      s_dwLastError = GetLastError();
      hb_ret();   // NIL
      return;
   }

   pA = StArray( &stL );
   hb_itemReturnRelease( pA );
   s_dwLastError = 0;
}

// TZ_LocalAUtc( nAno, nMes, nDia, nHora, nMin, nSeg ) -> aSt o NIL
// Conversion inversa: de hora local del huso activo a UTC.
// Cerca de los cambios de horario hay horas locales ambiguas o
// inexistentes sin resultado "correcto" garantizado (doc. Microsoft).
HB_FUNC( TZ_LOCALAUTC )
{
   SYSTEMTIME stL, stU;
   PHB_ITEM pA;

   RellenaST( &stL );

   if( ! TzSpecificLocalTimeToSystemTime( NULL, &stL, &stU ) )
   {
      s_dwLastError = GetLastError();
      hb_ret();   // NIL
      return;
   }

   pA = StArray( &stU );
   hb_itemReturnRelease( pA );
   s_dwLastError = 0;
}

// TZ_LastError() -> ultimo GetLastError() de las TZ_*
HB_FUNC( TZ_LASTERROR )
{
   hb_retnl( ( long ) s_dwLastError );
}
