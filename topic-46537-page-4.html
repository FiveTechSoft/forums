  • Node.js
    Bien, Node.js es un entorno de JavaScript.
    Para usar Node.js, parece buena idea usar Docker.

  • Docker
    Bien, Docker es una plataforma que permite empaquetar y ejecutar aplicaciones en entornos aislados.
