Short answer: FiveWin for Harbour can generate QR codes, but it has no built-in function to read (decode) them. We checked the current source and found no QR or barcode decoding code.

What FWH offers today:

  • Generation: see samples/qrcode.prg and source/classes/fwbarcod.prg.

  • TWebcam (source/classes/twebcam.prg): preview and capture of images or video only. It gives you a picture, it does not decode anything in it.

Options for reading (these are general, non-official approaches, not part of FWH):

  1. Hardware scanner that works as a keyboard. Most USB or Bluetooth QR scanners "type" the content into the focused GET, followed by Enter. For many applications this is the simplest solution: no extra code, the QR arrives as plain text.

  2. External decoding library such as ZXing or ZBar, called through a DLL or COM wrapper from your Harbour code. You could capture the image (for example with TWebcam, saving a BMP) and pass the file to the library, which returns the decoded text. This needs the external library and some wrapper work on your side.

Dear Antonio,

Thank you for the question. Here is how I would design a QR reader using only FWH and Harbour code, step by step:

  1. Image acquisition. Capture a frame with TWebcam/DirectShow (see samples/misc/dshow.prg) or load a BMP file.

  2. Preprocessing in pure Harbour. Convert to grayscale and binarize. An adaptive threshold per region works better than a global one when the lighting is uneven.

  3. Finder pattern detection. Scan rows and columns for the 1:1:3:1:1 run-length ratio of the three position patterns. From their centers you get the orientation, the module size and the grid.

  4. Grid sampling. Use the timing patterns (and the alignment pattern for version 2 or higher) to sample each module into a bit matrix.

  5. Format information. Read the 15 BCH format bits around the finder patterns. They give the error-correction level and the data mask. Then unmask the matrix.

  6. Codeword extraction. Read the data in zigzag order from the bottom-right corner and deinterleave the blocks.

  7. Reed-Solomon error correction. This uses GF(256) arithmetic. The FWH QR generator already carries the GF(256) tables and the encoding side. For decoding you need syndromes, Berlekamp-Massey and Forney. It is the heaviest piece, but perfectly doable in pure PRG.

  8. Payload decoding. Parse the mode indicators (numeric, alphanumeric, byte, kanji) and return the string.

Honest estimate of the effort: stages 1 to 6 are a few days of work. Stage 7 is the real project. It is a great exercise and very feasible in pure Harbour. For production scanning at scale, a hardware scanner (keyboard wedge) or an external decoder library remains the pragmatic route.

QR reader implemented in pure Harbour - included in FWH, available in the next build

Done and verified: a pure Harbour QR reader (about 1100 lines, no C code, no external dependencies). It is now in FWH:
https://github.com/FiveTechSoft/fwh/blob/master/samples/misc/qrread.prg

API

Code: Select all Collapse
QRReadFile( cBmp )
QRDecodeGray( aGray, nW, nH )
QRDecodeMatrix( aMat, nDim )

Each returns a hash with {text, version, ecl, mask, errors, dim, modes}, or NIL if nothing could be decoded.

What it covers (the 8 stages from the design post):

  • BMP loading (1, 4, 8, 24 and 32 bit)

  • Adaptive binarization

  • Finder patterns at any rotation

  • Grid sampling with a homography

  • BCH format information

  • Deinterleaving of the blocks

  • Reed-Solomon correction (GF 256, Berlekamp-Massey and Forney)

  • Numeric, alphanumeric, byte and kanji payload modes

Verified: 211 test cases, byte-exact. They include UTF-8, kanji, rotations of 90/180/270 and 17/45/-30 degrees, gradient plus noise plus blur, perspective, all 160 version/ECL combinations (v1-40 x L/M/Q/H), damage recovery up to 41 codewords and 6 BMP formats. Negative images safely return NIL. Tested on Linux and on Windows x64 under Wine.

Honest notes

  • The text field holds raw bytes: UTF-8 for most generators, and kanji returns Shift-JIS. Convert it if your application uses another codepage.

  • Mirrored, micro and inverted QR codes are not supported.

  • For a webcam: capture a frame with TWebcam and pass it as a BMP, or as grayscale to QRDecodeGray().

The reader is included in FWH and will be available in the next build.

/*
 * qrread.prg - QR code reader in pure Harbour (no C, no FWH dependency).
 *
 * Pipeline:
 *   1. QRBmpLoad()       BMP (1/4/8/24/32 bit) -> gray array
 *   2. QRBinarize()      adaptive (block min/max) threshold -> black/white
 *   3. QRFindFinders()   1:1:3:1:1 finder patterns, QRLocate() orientation,
 *                        module size, grid, alignment pattern
 *   4. QRSampleGrid()    homography sampling -> bit matrix
 *   5. QRReadFormat()    15-bit BCH format info (EC level + mask)
 *   6. QRExtract()       unmask, zigzag, de-interleave blocks
 *   7. QRRsCorrect()     Reed-Solomon GF(256): syndromes, Berlekamp-Massey,
 *                        Chien search, Forney
 *   8. QRParsePayload()  numeric / alphanumeric / byte / kanji / ECI
 *
 * API:
 *   QRReadFile( cBmp )                 -> hResult | NIL
 *   QRDecodeGray( aGray, nW, nH )      -> hResult | NIL
 *   QRDecodeMatrix( aMat, nDim )       -> hResult | NIL   (stages 5-8 only)
 *   hResult keys: text version ecl mask errors dim modes
 *   text holds the raw bytes of the payload (UTF-8 for most generators; kanji
 *   mode returns Shift-JIS bytes).
 *   aMat[ nRow ][ nCol ] = 1 black / 0 white, 1-based.
 */

//----------------------------------------------------------------------------//
// GF(256), primitive polynomial 0x11D
//----------------------------------------------------------------------------//

static function GFInit()
   local i, x := 1
   if s_aExp != NIL
      return nil
   endif
   s_aExp := Array( 512 )
   s_aLog := Array( 256 )
   AFill( s_aLog, 0 )
   for i := 0 to 254
      s_aExp[ i + 1 ] := x
      s_aLog[ x + 1 ] := i
      x := x * 2
      if x >= 256
         x := hb_bitXor( x, 285 )
      endif
   next
   for i := 255 to 511
      s_aExp[ i + 1 ] := s_aExp[ i - 255 + 1 ]
   next
return nil

static function GFMul( a, b )
   if a == 0 .or. b == 0
      return 0
   endif
return s_aExp[ s_aLog[ a + 1 ] + s_aLog[ b + 1 ] + 1 ]

static function GFDiv( a, b )
   if a == 0
      return 0
   endif
return s_aExp[ s_aLog[ a + 1 ] - s_aLog[ b + 1 ] + 255 + 1 ]

static function GFPow( n )          // alpha^n, any integer n
return s_aExp[ ( ( n % 255 ) + 255 ) % 255 + 1 ]

static function AlignPos( nVer )
   local aP := {}, n, nLast, nStep, k
   if nVer < 2
      return aP
   endif
   n     := Int( nVer / 7 ) + 2
   nLast := 4 * nVer + 10
   if nVer == 32
      nStep := 26
   else
      nStep := Int( ( nLast - 6 + ( n - 1 ) * 2 - 1 ) / ( ( n - 1 ) * 2 ) ) * 2
   endif
   AAdd( aP, 6 )
   for k := n - 2 to 0 step -1
      AAdd( aP, nLast - k * nStep )
   next
return aP

function QRReadAll( cFile )       // binary-safe whole-file read
#ifdef __XHARBOUR__
   local nH := FOpen( cFile, 0 ), cBuf := "", cChunk, nRead
   if nH < 0
      return ""
   endif
   cChunk := Space( 65536 )
   do while ( nRead := FRead( nH, @cChunk, 65536 ) ) > 0
      cBuf += Left( cChunk, nRead )
   enddo
   FClose( nH )
return cBuf
#else
return hb_MemoRead( cFile )          // byte exact, also under UTF8 codepages
#endif

function QRBmpLoad( cFile )
   local cS := QRReadAll( cFile )
   local nOff, nHdr, nW, nH, nBpp, nComp, nClr, nStride, lTop
   local aPal, i, x, y, nPos, nR, nG, nB, aG, nRow, nB1, nIdx

   if Len( cS ) < 54 .or. QRSub( cS, 1, 2 ) != "BM"
      return nil
   endif
   nOff  := Bin2L( QRSub( cS, 11, 4 ) )
   nHdr  := Bin2L( QRSub( cS, 15, 4 ) )
   nW    := Bin2L( QRSub( cS, 19, 4 ) )
   nH    := Bin2L( QRSub( cS, 23, 4 ) )
   nBpp  := Bin2W( QRSub( cS, 29, 2 ) )
   nComp := Bin2L( QRSub( cS, 31, 4 ) )
   nClr  := Bin2L( QRSub( cS, 47, 4 ) )
   if nComp != 0 .and. ! ( nComp == 3 .and. nBpp == 32 )
      return nil
   endif
   lTop := ( nH < 0 )
   nH   := Abs( nH )
   if nW <= 0 .or. nH <= 0
      return nil
   endif
   nStride := Int( ( nW * nBpp + 31 ) / 32 ) * 4

   aPal := {}
   if nBpp <= 8
      if nClr == 0
         nClr := 2 ^ nBpp
      endif
      for i := 0 to nClr - 1
         nPos := 14 + nHdr + i * 4
         nB := QRByte( cS, nPos + 1 )
         nG := QRByte( cS, nPos + 2 )
         nR := QRByte( cS, nPos + 3 )
         AAdd( aPal, Int( ( 299 * nR + 587 * nG + 114 * nB ) / 1000 ) )
      next
   endif

   aG := Array( nW * nH )
   for y := 0 to nH - 1
      nRow := nOff + If( lTop, y, nH - 1 - y ) * nStride     // 0-based byte offset
      for x := 0 to nW - 1
         do case
         case nBpp == 24 .or. nBpp == 32
            nPos := nRow + x * ( nBpp / 8 )
            nB := QRByte( cS, nPos + 1 )
            nG := QRByte( cS, nPos + 2 )
            nR := QRByte( cS, nPos + 3 )
            aG[ y * nW + x + 1 ] := Int( ( 299 * nR + 587 * nG + 114 * nB ) / 1000 )
         case nBpp == 8
            nIdx := QRByte( cS, nRow + x + 1 )
            aG[ y * nW + x + 1 ] := If( nIdx < Len( aPal ), aPal[ nIdx + 1 ], 0 )
         case nBpp == 4
            nB1 := QRByte( cS, nRow + Int( x / 2 ) + 1 )
            nIdx := If( x % 2 == 0, Int( nB1 / 16 ), nB1 % 16 )
            aG[ y * nW + x + 1 ] := If( nIdx < Len( aPal ), aPal[ nIdx + 1 ], 0 )
         case nBpp == 1
            nB1 := QRByte( cS, nRow + Int( x / 8 ) + 1 )
            nIdx := If( QRBit( nB1, 7 - ( x % 8 ) ), 1, 0 )
            aG[ y * nW + x + 1 ] := If( nIdx < Len( aPal ), aPal[ nIdx + 1 ], 0 )
         otherwise
            return nil
         endcase
      next
   next
return { nW, nH, aG }

//----------------------------------------------------------------------------//
// 2. Binarization: Otsu global + local block min/max (3x3 blocks of 16 px)
//    returns flat array, 1 = black
//----------------------------------------------------------------------------//

function QRBinarize( aG, nW, nH )
   local aHist := Array( 256 ), i, nTot := nW * nH, nSum := 0, nSumB := 0
   local nWB := 0, nWF, nMax := -1, nOtsu := 128, nMB, nMF, nVar
   local nBS := 16, nBX := Int( ( nW + nBS - 1 ) / nBS ), nBY := Int( ( nH + nBS - 1 ) / nBS )
   local aMin := Array( nBX * nBY ), aMax := Array( nBX * nBY )
   local bx, by, x, y, g, k, lo, hi, thr, ix, iy, nB, aBin := Array( nTot )
   local aThr := Array( nBX * nBY ), x0, x1, y0, y1

   AFill( aHist, 0 )
   for i := 1 to nTot
      aHist[ aG[ i ] + 1 ]++
   next
   for i := 0 to 255
      nSum += i * aHist[ i + 1 ]
   next
   for i := 0 to 255
      nWB += aHist[ i + 1 ]
      if nWB == 0
         loop
      endif
      nWF := nTot - nWB
      if nWF == 0
         exit
      endif
      nSumB += i * aHist[ i + 1 ]
      nMB := nSumB / nWB
      nMF := ( nSum - nSumB ) / nWF
      nVar := nWB * nWF * ( nMB - nMF ) ^ 2
      if nVar > nMax
         nMax := nVar
         nOtsu := i
      endif
   next
   nOtsu++      // pixel < threshold  =>  black

   for by := 0 to nBY - 1
      for bx := 0 to nBX - 1
         lo := 255
         hi := 0
         x1 := Min( nW, ( bx + 1 ) * nBS ) - 1
         y1 := Min( nH, ( by + 1 ) * nBS ) - 1
         for y := by * nBS to y1
            for x := bx * nBS to x1
               g := aG[ y * nW + x + 1 ]
               if g < lo ; lo := g ; endif
               if g > hi ; hi := g ; endif
            next
         next
         aMin[ by * nBX + bx + 1 ] := lo
         aMax[ by * nBX + bx + 1 ] := hi
      next
   next
   for by := 0 to nBY - 1
      for bx := 0 to nBX - 1
         lo := 255
         hi := 0
         for iy := Max( 0, by - 1 ) to Min( nBY - 1, by + 1 )
            for ix := Max( 0, bx - 1 ) to Min( nBX - 1, bx + 1 )
               k := iy * nBX + ix + 1
               if aMin[ k ] < lo ; lo := aMin[ k ] ; endif
               if aMax[ k ] > hi ; hi := aMax[ k ] ; endif
            next
         next
         if hi - lo >= 40
            thr := ( lo + hi ) / 2
         else

         endif

static function RdBits( oR, n )
   local v := 0, i
   if oR[2] + n - 1 > Len( oR[1] )
      return -1
   endif
   for i := 1 to n
      v := v * 2 + oR[1][ oR[2] ]
      oR[2]++
   next
return v

static function BitsOf( aData )
   local aB := {}, i, j, c
   for i := 1 to Len( aData )
      c := aData[i]
      for j := 7 to 0 step -1
         AAdd( aB, If( QRBit( c, j ), 1, 0 ) )
      next
   next
return aB

// returns { cText, cModes } or NIL
function QRParsePayload( aData, nVer )
   local oR := { BitsOf( aData ), 1 }, cOut := "", cModes := "", nMode, nCnt, v, i
   local cAlnum := "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ $%*+-./:", n, w, hi, lo

   do while Len( oR[1] ) - oR[2] + 1 >= 4
      nMode := RdBits( oR, 4 )
      if nMode == 0
         exit
      endif
      do case
      case nMode == 1 .or. nMode == 2 .or. nMode == 4 .or. nMode == 8
         nCnt := RdBits( oR, CountBits( nVer, nMode ) )
         if nCnt < 0
            return nil
         endif
         do case
         case nMode == 1
            cModes += "N"
            do while nCnt >= 3
               v := RdBits( oR, 10 ) ; if v < 0 .or. v > 999 ; return nil ; endif
               cOut += PadL( hb_NToS( v ), 3, "0" ) ; nCnt -= 3
            enddo
            if nCnt == 2
               v := RdBits( oR, 7 ) ; if v < 0 .or. v > 99 ; return nil ; endif
               cOut += PadL( hb_NToS( v ), 2, "0" )
            elseif nCnt == 1
               v := RdBits( oR, 4 ) ; if v < 0 .or. v > 9 ; return nil ; endif
               cOut += hb_NToS( v )
            endif
         case nMode == 2
            cModes += "A"
            do while nCnt >= 2
               v := RdBits( oR, 11 ) ; if v < 0 .or. v >= 45 * 45 ; return nil ; endif
               cOut += SubStr( cAlnum, Int( v / 45 ) + 1, 1 ) + SubStr( cAlnum, v % 45 + 1, 1 )
               nCnt -= 2
            enddo
            if nCnt == 1
               v := RdBits( oR, 6 ) ; if v < 0 .or. v >= 45 ; return nil ; endif
               cOut += SubStr( cAlnum, v + 1, 1 )
            endif
         case nMode == 4
            cModes += "B"
            for i := 1 to nCnt
               v := RdBits( oR, 8 ) ; if v < 0 ; return nil ; endif
               cOut += QRChr( v )
            next
         otherwise
            cModes += "K"
            for i := 1 to nCnt
               v := RdBits( oR, 13 ) ; if v < 0 ; return nil ; endif
               hi := Int( v / 192 ) ; lo := v % 192
               n  := hi * 256 + lo
               if n + 33088 <= 40956                      // 0x8140 .. 0x9FFC
                  n += 33088
               else
                  n += 49472                              // 0xC140
               endif
               cOut += QRChr( Int( n / 256 ) ) + QRChr( n % 256 )
            next
         endcase
      case nMode == 7                                      // ECI
         v := RdBits( oR, 8 )
         if v < 0 ; return nil ; endif
         if v >= 192
            RdBits( oR, 16 )
         elseif v >= 128
            RdBits( oR, 8 )
         endif
         cModes += "E"
      case nMode == 3                                      // structured append
         RdBits( oR, 16 )
         cModes += "S"
      case nMode == 5
         cModes += "F"
      case nMode == 9
         RdBits( oR, 8 )
         cModes += "F"
      otherwise
         return nil
      endcase
   enddo
return { cOut, cModes }

function QRDecodeMatrix( aM, nDim )
   local nVer, aF, nLevel, aCW, aBlk, aData := {}, i, j, aR, nFix := 0, n, aP, nEC
   local aLevels := { "M", "L", "H", "Q" }

   GFInit()
   if nDim < 21 .or. nDim > 177 .or. ( nDim - 17 ) % 4 != 0
      return nil
   endif
   nVer := ( nDim - 17 ) / 4
   aF := ReadFormat( aM, nDim )
   if aF == nil
      return nil
   endif
   nLevel := { 2, 1, 4, 3 }[ aF[1] + 1 ]        // ec bits 0=M 1=L 2=H 3=Q  -> index L1 M2 Q3 H4
   aCW := ExtractCodewords( aM, nDim, nVer, aF[2] )
   aBlk := Deinterleave( aCW, nVer, nLevel )
   if aBlk == nil
      return nil
   endif
   for i := 1 to Len( aBlk )
      nEC := Len( aBlk[i][2] )
      aR := ArrayJoin( aBlk[i][1], aBlk[i][2] )
      n := QRRsCorrect( aR, nEC )
      if n < 0
         return nil
      endif
      nFix += n
      for j := 1 to Len( aBlk[i][1] )
         AAdd( aData, aR[j] )
      next
   next
   aP := QRParsePayload( aData, nVer )
   if aP == nil
      return nil
   endif
return { "text" => aP[1], "version" => nVer, "ecl" => aLevels[ aF[1] + 1 ], "mask" => aF[2], ;
         "errors" => nFix, "dim" => nDim, "modes" => aP[2] }

static function ArrayJoin( a, b )
   local r := AClone( a ), i
   for i := 1 to Len( b )
      AAdd( r, b[i] )
   next
return r

function QRDecodeGray( aG, nW, nH )
   local aBin := QRBinarize( aG, nW, nH ), aCand, aT, TL, TR, BL, nMod, nDimEst, nVEst
   local aTry, nV, nDim, aAP, aH, aM, aRes, k, aPts, aUV, aXY, nOff, lAlignTried

   aCand := FindFinders( aBin, nW, nH )
   if Len( aCand ) < 3
      return nil
   endif
   aT := PickTriple( aCand )
   if aT == nil
      return nil
   endif
   TL := aT[1] ; TR := aT[2] ; BL := aT[3]
   nMod := ( TL[3] + TR[3] + BL[3] ) / 3
   nDimEst := ( Dist( TL, TR ) + Dist( TL, BL ) ) / 2 / nMod + 7
   nVEst := Max( 1, Min( 40, Round( ( nDimEst - 17 ) / 4, 0 ) ) )

   aTry := { nVEst }
   for k := 1 to 3
      if nVEst - k >= 1 ; AAdd( aTry, nVEst - k ) ; endif
      if nVEst + k <= 40 ; AAdd( aTry, nVEst + k ) ; endif
   next
   for k := 1 to Len( aTry )
      nV := aTry[k]
      nDim := 17 + 4 * nV
      aAP := If( nV >= 2, FindAlign( aBin, nW, nH, TL, TR, BL, nDim ), nil )
      for nOff := 1 to 2
         if nOff == 1 .and. aAP == nil
            loop
         endif
         aUV := { { 3.5, 3.5 }, { nDim - 3.5, 3.5 }, { 3.5, nDim - 3.5 }, { nDim - 6.5, nDim - 6.5 } }
         aXY := { { TL[1], TL[2] }, { TR[1], TR[2] }, { BL[1], BL[2] }, Nil }
         if nOff == 1
            aXY[4] := aAP
         else
            aUV[4] := { nDim - 3.5, nDim - 3.5 }
            aXY[4] := { TR[1] + BL[1] - TL[1], TR[2] + BL[2] - TL[2] }
         endif
         aH := Homography( aUV, aXY )
         if aH == nil
            loop
         endif
         aM := SampleGrid( aBin, nW, nH, aH, nDim )
         aRes := QRDecodeMatrix( aM, nDim )
         if aRes != nil
            return aRes
         endif
      next
   next
return nil

function QRReadFile( cBmp )
   local aImg := QRBmpLoad( cBmp )
   if aImg == nil
      return nil
   endif
return QRDecodeGray( aImg[3], aImg[1], aImg[2] )

Dear Jimmy,

Thank you for testing it. This error is not in the reader code. It is a link error in your build: the linker cannot find the Harbour GT driver HB_GT_WIN, which lives in a library that is not in your link list. Adding REQUEST HB_GT_WIN cannot fix it, because that line only asks for the symbol, it does not bring in the library. Please remove it.

About the header: the first lines of qrread.prg are already inside a /* ... / comment block in the posted code. If you got an error about lines 1-14, check that you copied from the very first line "/" of the first code block and that the three posts were pasted one after the other. The code in the 3 posts is identical to the original file.

What to do:

  1. Build it with the same script FWH uses for its samples: samples\buildh64.bat (for a 64 bit exe). It links the right GT library (gtgui.lib), so you do not need any REQUEST for the GT.

  2. If you use your own build script, add the missing library to the link list. Either gtgui.lib, as buildh64.bat does, or gtwin.lib for a console program, from your Harbour lib folder.

  3. qrread.prg has no Main(). It is a library of functions. To test it, add your own small Main(), for example:

   endif
