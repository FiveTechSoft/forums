Hola Jair,



Sí, pero conviene separar dos cosas: las etiquetas que aparecen junto a cada campo y el título de la ventana.



En EditSource(), el segundo parámetro es la lista de campos del origen, no una lista de etiquetas alternativas. Si los campos se llaman "unid" y "desc", no debes sustituirlos ahí por "Unidade" y "Descrição".



He revisado el código actual de FWH: TDataRow dispone del método SetPrompt() para asignar una etiqueta distinta a un campo, conservando su nombre real. Para este caso, la correspondencia sería "unid" con "Unidade" y "desc" con "Descrição". EditSource() también admite, en esa versión, un quinto parámetro bSetup que recibe el objeto TDataRow antes de abrir el editor; es el punto donde se pueden preparar esas etiquetas, sin renombrar las columnas de MySQL.



El título de la ventana se trata aparte: no lo determina esa lista de campos. TDataRow tiene cTitle y su método Edit() admite un título explícito. No es lo mismo cambiar el título que cambiar las etiquetas.



No he ejecutado tu caso ni sé aún si tu versión incluye esos parámetros. ¿Qué versión de FWH utilizas, con qué clase accedes a MySQL, y quieres cambiar las etiquetas, el título de la ventana o ambos? Con eso podemos concretar la llamada que corresponde a tu entorno.

FUNCTION fTestarCadCli( oCn, oWndMain )

   LOCAL bSetupInc, bSetupAlt

      MsgStop( "Conexão SQL não informada.", "Erro" )
      RETURN NIL
   ENDIF

   IF ! oCn:TableExists( cTabela )
      MsgStop( "A tabela '" + cTabela + "' não foi encontrada no banco SQL." + CRLF + ;
               "Importe-a primeiro usando as opções do Dicionário.", "Atenção" )
      RETURN NIL
   ENDIF

   oRsCli := oCn:RowSet( "SELECT * FROM " + cTabela + " ORDER BY UNID" )
   IF oRsCli == NIL
      MsgStop( "Não foi possível abrir os dados da tabela " + cTabela, "Erro" )
      RETURN NIL
   ENDIF

   // Colunas do GRID (títulos curtos)

      { "ID",    "ID",         nil,  60 }, ;
      { "UNID",  "Unid",       nil,  80 }, ;
      { "DESCR", "Descrição",  nil, 280 }  ;
   }

   bSetupInc := { | oRec | ;
      oRec:SetPrompt( "UNID",  "Unidade" ), ;
      oRec:SetPrompt( "DESCR", "Descrição" ), ;
      oRec:cTitle := "Incluir unidade" }

   bSetupAlt := { | oRec | ;
      oRec:SetPrompt( "UNID",  "Unidade" ), ;
      oRec:SetPrompt( "DESCR", "Descrição" ), ;
      oRec:cTitle := "Alterar unidade" }

   DEFINE WINDOW oWndCli MDICHILD OF oWndMain ;
      TITLE "Dicionário - Manutenção de Unidades (CADUNID)"

   DEFINE BUTTONBAR oBar OF oWndCli 2007 SIZE 70, 55 LEFT

   // NOVO: EditSource( .T. ) = incluir  |  lista = nomes REAIS dos campos
   DEFINE BUTTON OF oBar PROMPT "Novo" RESOURCE "add" ;
      ACTION ( oBrw:EditSource( .T., cCamposEd, , , bSetupInc ), oBrw:Refresh() ) ;
      TOOLTIP "Incluir unidade"

   // NOVO: EditSource( .T. ) = incluir  |  lista = nomes REAIS dos campos
   DEFINE BUTTON OF oBar PROMPT "Alterar" RESOURCE "edit" ;
      ACTION ( oBrw:EditSource( .f., cCamposEd, , , bSetupAlt ), oBrw:Refresh() ) ;
      TOOLTIP "Alterar unidade"


   DEFINE BUTTON OF oBar PROMPT "Excluir" RESOURCE "deleted" ;
      ACTION CadUnidExcluir( oRsCli, oBrw ) ;
      TOOLTIP "Apagar registro"

   SEPARATOR

   DEFINE BUTTON OF oBar PROMPT "Excel" RESOURCE "EXCEL" ;
      ACTION oBrw:ToExcel() ;

Disculpa: mi primera respuesta se refería a la barra del grid. Veo tu aclaración: quieres mantener esa barra y mover los botones del diálogo de edición. No cambies el LEFT de oBar para eso.



En la implementación actual de TDataRow, el diálogo de EditSource crea sus botones debajo del panel de campos. No usa la BUTTONBAR oBar de tu ventana, y no hay un parámetro TOP en EditSource para recolocarlos.



Además, no basta con mover los botones una vez: el código de redimensionado del diálogo vuelve a situarlos debajo del panel. Para ponerlos arriba habría que adaptar la distribución del editor, o usar un diálogo de edición propio mediante bEdit, conservando las acciones de guardar y cancelar.

static function CadUnidExcluir( oRs, oBrw )

   LOCAL lConfirma := .F.

   // Verifica se o Recordset está válido e tem um registro selecionado
   IF oRs == NIL .OR. ! oRs:IsValid()
      MsgAlert( "Nenhum registro selecionado!", "Atenção" )
      RETURN .F.
   ENDIF

   // Confirmação antes de excluir
   lConfirma := MsgYesNo( "Deseja realmente excluir esta unidade?" + CRLF + ;
                          "Essa operação não pode ser desfeita!", ;
                          "Confirmação de Exclusão" )

   IF lConfirma
      BEGIN TRY
         oRs:Delete()          // Marca registro para exclusão
         oRs:MoveNext()        // Avança para não ficar no registro apagado
         IF oRs:Eof() .AND. ! oRs:Bof()
            oRs:MovePrev()     // Se chegou no fim, volta um
         ENDIF
         oBrw:Refresh()        // Atualiza a visualização do grid

     MsgInfo( "Registro excluído com sucesso!", "Sucesso" )
  CATCH oErr
     MsgStop( "Erro ao excluir registro:" + CRLF + ;
              oErr:description, "Erro" )
     RETURN .F.
  END TRY
   ENDIF

RETURN .T.
