Las 8 formas del nombre del equipo con GetComputerNameEx

Hola a todos:

Seguimos con la serie de ejemplos de programación Windows con FiveWin. Hoy, una API pequeña pero con más matices de los que parece: GetComputerNameEx no devuelve "el nombre del equipo" a secas, sino ocho formas distintas, y conviene saber cuál pedir en cada caso.

Las 8 formas (COMPUTER_NAME_FORMAT)

Según la documentación de Microsoft:

  • NetBIOS: el nombre NetBIOS del equipo.
  • DNS hostname: el nombre de host DNS.
  • DNS domain: el dominio DNS asignado al equipo.
  • DNS FQDN: el nombre completo, HostName.DominioDNS.
  • Y las cuatro variantes "Physical": en un equipo en clúster, las formas normales pueden devolver el nombre del servidor virtual del clúster, mientras que las Physical devuelven el del propio equipo.

Detalles documentados que importan al usarla:

  • Los nombres se leen del registro al arrancar el sistema: un cambio con SetComputerName/SetComputerNameEx no se refleja hasta reiniciar.
  • Si el equipo no está configurado para usar nombres DNS, la función no devuelve información DNS.
  • Un nombre DNS puede superar MAX_COMPUTERNAME_LENGTH; la documentación permite llamar con buffer NULL para averiguar primero el tamaño necesario. El ejemplo usa un buffer fijo de 512 bytes y reporta el error si no bastara.
  • Requiere Windows 2000 o superior; al compilar, el SDK debe definir _WIN32_WINNT >= 0x0500.

El ejemplo completo

Una ventana con un botón que consulta las ocho formas y las muestra lado a lado, para compararlas de un vistazo. El código C embebido va en el propio PRG y llama a la versión ANSI, GetComputerNameExA, para trabajar con cadenas de un byte; la versión Unicode es GetComputerNameExW.

//----------------------------------------------------------------------------//
// GCNAME.PRG (v2)
// Las 8 formas del nombre de equipo con GetComputerNameEx
// Ejemplo didactico FiveWin (FWH) + Harbour
//
// Que muestra:
//   - GetComputerNameEx con cada COMPUTER_NAME_FORMAT: NetBIOS, DNS
//     (hostname, dominio, FQDN) y sus variantes "Physical"
//   - Diferencia documentada: las formas normales pueden devolver el
//     nombre del servidor virtual del cluster; las "Physical", el del
//     propio equipo (doc. Microsoft)
//   - Los nombres se leen del registro al arrancar el sistema: los
//     cambios con SetComputerName/SetComputerNameEx no valen hasta
//     reiniciar (doc. Microsoft)
//   - Si el equipo no esta configurado para usar nombres DNS, la
//     funcion no devuelve informacion DNS (doc. Microsoft); la prueba
//     muestra lo que devuelve cada forma en ese equipo
//
// Ojo con el buffer: un nombre DNS puede superar MAX_COMPUTERNAME_LENGTH;
// la doc. permite llamar con buffer NULL para obtener el tamaño justo.
// Aqui usamos 512 bytes fijos y reportamos el error si no bastan.
//
// v2: los 8 SAYs de valores ya no usan VAR aVals[i]: el xcommand SAY
// convierte el texto en un bloque que capturaba la i del FOR por
// referencia; al refrescar, i ya valia 9 y aVals[9] lanzaba BASE/1132.
// Ahora los SAYs nacen con PROMPT "" y se escriben con TSay:SetText().
// v2 tambien precisa la nota DNS para citar la doc. sin extrapolar
// el resultado de cada forma.
// v3: geometria. Las 8 filas empezaban en y=99, bajo el boton Consultar
// (y=85..111), y el valor NetBIOS quedaba oculto tras el; ademas la
// fila 8 pisaba la linea de estado. Filas desde y=118, estado a 310,
// Cerrar a 340 y ventana 435 de alto. Sin cambios funcionales.
//
// Documentacion de Microsoft:
//   https://learn.microsoft.com/en-us/windows/win32/api/sysinfoapi/nf-sysinfoapi-getcomputernameexw
//----------------------------------------------------------------------------//

#include "FiveWin.ch"

static aForms := { "NetBIOS", "DNS hostname", "DNS domain", "DNS FQDN", ;
                   "Physical NetBIOS", "Physical DNS hostname", ;
                   "Physical DNS domain", "Physical DNS FQDN" }
static aSayVal
static cTxtEstado := "Pulsa Consultar para leer las 8 formas"
static oSayEstado

//----------------------------------------------------------------------------//

function Main()

   local oWnd
   local i, nY

   aSayVal := Array( 8 )

   DEFINE WINDOW oWnd ;
      FROM 0, 0 TO 435, 460 PIXEL ;
      TITLE "GetComputerNameEx: las 8 formas del nombre"

   @ 15, 15 SAY "GetComputerNameEx devuelve el nombre del equipo local" OF oWnd SIZE 430, 15 PIXEL

   @ 33, 15 SAY "en formas NetBIOS y DNS (host, dominio, FQDN), y 'Physical'." OF oWnd SIZE 430, 15 PIXEL

   @ 58, 15 SAY "Si el equipo no usa DNS, no devuelve informacion DNS (doc. Microsoft)." OF oWnd SIZE 430, 15 PIXEL

   @ 85, 125 BUTTON "Consultar las 8 formas" OF oWnd ;
      SIZE 210, 26 PIXEL ACTION BtnConsultar()

   for i := 1 to 8
      nY := 118 + ( i - 1 ) * 24
      @ nY, 15 SAY aForms[ i ] + ":" OF oWnd SIZE 185, 18 PIXEL
      @ nY, 205 SAY aSayVal[ i ] PROMPT "" OF oWnd SIZE 240, 18 PIXEL
   next

   @ 310, 15 SAY oSayEstado VAR cTxtEstado OF oWnd SIZE 430, 20 PIXEL

   @ 340, 180 BUTTON "Cerrar" OF oWnd SIZE 100, 26 PIXEL ACTION oWnd:End()

   ACTIVATE WINDOW oWnd CENTERED

return nil

//----------------------------------------------------------------------------//

static function BtnConsultar()

   local i, cRes, nFallos := 0

   for i := 1 to 8
      cRes := GCN_GetName( i - 1 )   // formas 0..7 (COMPUTER_NAME_FORMAT)
      if cRes == NIL
         aSayVal[ i ]:SetText( "(error " + ;
                               AllTrim( Str( GCN_LastError() ) ) + ")" )
         nFallos++
      elseif Empty( cRes )
         aSayVal[ i ]:SetText( "(vacia)" )  // forma sin informacion aqui
      else
         aSayVal[ i ]:SetText( cRes )
      endif
   next

   if nFallos == 0
      cTxtEstado := "8 formas leidas del registro de arranque del equipo"
   else
      cTxtEstado := "Consulta con " + AllTrim( Str( nFallos ) ) + ;
                    " formas con error"
   endif

   oSayEstado:Refresh()

return nil

//----------------------------------------------------------------------------//

#pragma BEGINDUMP

#include <windows.h>
#include "hbapi.h"

// Ultimo GetLastError() de GCN_GetName
static DWORD s_dwLastError = 0;

// GCN_GetName( nForma0a7 ) -> cNombre o NIL
// Traduce el indice al enum COMPUTER_NAME_FORMAT por nombre (sin
// depender de sus valores numericos) y llama a GetComputerNameExA
// con un buffer fijo de 512 bytes (doc.: el nombre DNS puede superar
// MAX_COMPUTERNAME_LENGTH).
HB_FUNC( GCN_GETNAME )
{
   int idx = hb_parni( 1 );
   COMPUTER_NAME_FORMAT fmt;
   char buf[ 512 ];
   DWORD dwSize = sizeof( buf );

   switch( idx )
   {
      case 0: fmt = ComputerNameNetBIOS;                 break;
      case 1: fmt = ComputerNameDnsHostname;             break;
      case 2: fmt = ComputerNameDnsDomain;               break;
      case 3: fmt = ComputerNameDnsFullyQualified;       break;
      case 4: fmt = ComputerNamePhysicalNetBIOS;         break;
      case 5: fmt = ComputerNamePhysicalDnsHostname;     break;
      case 6: fmt = ComputerNamePhysicalDnsDomain;       break;
      case 7: fmt = ComputerNamePhysicalDnsFullyQualified; break;
      default:
         s_dwLastError = 87;   // ERROR_INVALID_PARAMETER
         hb_ret();             // NIL
         return;
   }

   if( GetComputerNameExA( fmt, buf, &dwSize ) )
   {
      hb_retc( buf );
      s_dwLastError = 0;
   }
   else
   {
      s_dwLastError = GetLastError();
      hb_ret();   // NIL
   }
}

// GCN_LastError() -> ultimo GetLastError() de GCN_GetName
HB_FUNC( GCN_LASTERROR )
{
   hb_retnl( ( long ) s_dwLastError );
}

#pragma ENDDUMP

//----------------------------------------------------------------------------//

Cómo probarlo

  1. Compilar con un toolchain como el de la sección Validación (FWH + Harbour + MinGW con _WIN32_WINNT >= 0x0500); la API vive en kernel32, sin librerías extra. No está probado con otros compiladores ni SDK antiguos.
  2. Pulsar "Consultar las 8 formas": cada fila muestra el valor devuelto, "(vacia)" si la forma no tiene información, o el código de error si la llamada falla.

Validación del ejemplo (medida, no supuesta)

Corrida de validación del 7 de noviembre de 2026 con Harbour 3.2.1dev (r2608271822), FWH 26.10 (FW_VersionNo 26080), llvm-mingw 20261020 (UCRT), ejecutado en Wine 11.19. El entorno de prueba arrancó con nombres de prueba fijados antes de la ejecución (EQUIPO-PRUEBAS / equipo-pruebas). Resultado medido al pulsar Consultar:

  • NetBIOS y Physical NetBIOS: EQUIPO-PRUEBAS.
  • DNS hostname y DNS FQDN (y sus Physical): equipo-pruebas.
  • DNS domain y Physical DNS domain: vacías.

Ojo al matiz: la documentación dice que un equipo no configurado para DNS no devuelve información DNS, y sin embargo en esta ejecución en Wine hostname y FQDN sí devolvieron el nombre de host aun con el dominio vacío. Es lo observado en ese Wine, no una afirmación sobre Windows nativo: en Windows real el comportamiento puede ser distinto y no lo hemos probado. Tampoco hemos probado el comportamiento en clúster (las formas Physical) ni el efecto de renombrar y reiniciar; ambos quedan como comportamiento documentado por Microsoft. Las dos capturas adjuntas, antes y después de Consultar, proceden de esa corrida del 7 de noviembre en Wine.
