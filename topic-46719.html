¿Puedes decirme algo al respecto Fivetech IA?
Te diré que le he preguntado a Instinct por el problema y lo ha solucionado facilitándome un nuevo printdc.c modificado por ella. Esta es la explicación que me ha dado:

En FiveWin 26.03, la impresora elegida con PrinterSetup() no se conserva entre trabajos de impresión. Al cerrar un TPrinter (ENDPRINT), TPrinter:End() llama a PrinterEnd(), que libera pd.hDevNames y pd.hDevMode y deja bInit=FALSE. El siguiente PrinterInit() vuelve a consultar Windows con PD_RETURNDEFAULT, así que se recupera la impresora predeterminada y se pierde la elegida con sus ajustes de driver.

Esto afecta también a cualquier código que cree y cierre un PRINT solo para consultar cModel: ese cierre borra la selección global.

Propuesta: guardar, al aceptar PrinterSetup(), una copia completa de DEVNAMES y DEVMODE (con los datos privados del driver), independiente del estado del trabajo. PrinterInit() la restauraría clonándola en lugar de consultar Windows. PrinterEnd() seguiría liberando el trabajo igual. La copia se sustituye en cada aceptación, se libera al salir del proceso y no cambia la impresora predeterminada de Windows.

Idealmente, como opciones explícitas de FiveWin: conservar la configuración entre trabajos y reiniciarla a la predeterminada de Windows, sin cambiar PrinterEnd() globalmente.

Limitaciones: PrinterSetup() devuelve 0 igual al cancelar que ante un error, y no se ha probado con otros drivers, xHarbour ni 64 bits.

/* Agrario v44: session copy of the last accepted printer setup.
   The working PRINTDLG still belongs to FiveWin and is freed by PrinterEnd.
   Keep the entire blocks, including the driver's private DEVMODE bytes. */
static HGLOBAL agrNames = NULL;
static HGLOBAL agrMode  = NULL;
static BOOL agrExitRegistered = FALSE;

static void AgrFreeSession( void )
{
   if( agrNames ) GlobalFree( agrNames );
   if( agrMode ) GlobalFree( agrMode );
   agrNames = agrMode = NULL;
}

static HGLOBAL AgrCloneBlock( HGLOBAL source )
{
   HGLOBAL copy;
   LPVOID from, to;
   SIZE_T size;

   if( ! source ) return NULL;
   size = GlobalSize( source );
   if( ! size ) return NULL;
   copy = GlobalAlloc( GMEM_MOVEABLE | GMEM_ZEROINIT, size );
   if( ! copy ) return NULL;
   from = GlobalLock( source );
   to = GlobalLock( copy );
   if( ! from || ! to )
   {
      if( from ) GlobalUnlock( source );
      if( to ) GlobalUnlock( copy );
      GlobalFree( copy );
      return NULL;
   }
   memcpy( to, from, size );
   GlobalUnlock( source );
   GlobalUnlock( copy );
   return copy;
}

static void AgrSaveSession( void )
{
   HGLOBAL names = AgrCloneBlock( pd.hDevNames );
   HGLOBAL mode = AgrCloneBlock( pd.hDevMode );

   if( ! names || ! mode )
   {
      if( names ) GlobalFree( names );
      if( mode ) GlobalFree( mode );
      MessageBoxA( GetActiveWindow(),
         "No se han podido guardar los ajustes de impresora para esta sesion.",
         "Impresora", MB_OK | MB_ICONWARNING );
      return;
   }
   AgrFreeSession();
   agrNames = names;
   agrMode = mode;
   if( ! agrExitRegistered )
   {
      agrExitRegistered = ( atexit( AgrFreeSession ) == 0 );
   }
}

static BOOL AgrRestoreSession( void )
{
   HGLOBAL names = AgrCloneBlock( agrNames );
   HGLOBAL mode = AgrCloneBlock( agrMode );

   if( ! names || ! mode )
   {
      if( names ) GlobalFree( names );
      if( mode ) GlobalFree( mode );
      MessageBoxA( GetActiveWindow(),
         "No se han podido recuperar los ajustes de impresora de esta sesion.",
         "Impresora", MB_OK | MB_ICONWARNING );
      return FALSE;
   }
   if( pd.hDevNames ) GlobalFree( pd.hDevNames );
   if( pd.hDevMode ) GlobalFree( pd.hDevMode );
   pd.hDevNames = names;
   pd.hDevMode = mode;
   return TRUE;
}

static void PrinterInit( void )
{
   if( ! bInit )
   {
      bInit = TRUE;
      memset( ( char * ) &pd, 0, sizeof( PRINTDLG ) );
      pd.lStructSize = sizeof( PRINTDLG );
      pd.hwndOwner   = GetActiveWindow();
      pd.Flags       = PD_RETURNDEFAULT ;
      pd.nFromPage   = 1;
      pd.nToPage     = 1;
      pd.nMinPage    = 1;
      pd.nMaxPage    = 65535;
      pd.nCopies     = 1;
      if( agrNames && agrMode )
         AgrRestoreSession();
      else
         PrintDlg( &pd );
   }
}

static void SendFile(HDC hPrnDC, LPSTR szFile)
{
  static LPPTS lpPTS=NULL;          // Pointer to PASSTHROUGHSTRUCT
  OFSTRUCT ofs;
  HFILE hFile;

  hFile = OpenFile((LPSTR) szFile, &ofs, OF_READ);
  if (hFile == HFILE_ERROR)
    {
    hb_retni(0);
    return;
    }

  if (!lpPTS &&
       !(lpPTS = (LPPTS)GlobalLock(GlobalAlloc(GPTR, sizeof(WORD) + BUFSIZE))))
    {
    hb_retni(0);
    return;
    }

  do {
    lpPTS->wSize = _lread(hFile, lpPTS->bData, BUFSIZE);
    Escape(hPrnDC, PASSTHROUGH, NULL, (LPSTR)lpPTS, NULL);
    }
  while ((lpPTS->wSize == BUFSIZE));

  _lclose(hFile);
  hb_retni(1);

}

Estimado Manuel:

Con tu ejemplo se ve exactamente dónde se pierde la selección: el primer preview usa la impresora elegida, pero al cerrarlo TPrinter:End() llama a PrinterEnd(), que libera la configuración del diálogo. La siguiente PrinterSetup() vuelve a consultar la predeterminada de Windows. No hace falta cambiar esa predeterminada.

Hemos revisado el historial: esa llamada a PrinterEnd() se activó en febrero de 2013 para corregir una fuga de memoria, y desde entonces se ha mantenido. Por eso no conviene quitarla sin más. Si tu versión anterior conservaba la selección durante toda la sesión, habría que comparar también la printer.prg y las librerías que estabas usando entonces.

Para recordar el destino entre informes, con la API actual puedes guardar PrnGetName() justo después de aceptar PrinterSetup() y usar PRINT ... TO cPrinter en los informes siguientes:

Code: Select all Collapse
STATIC cPrinter := ""

STATIC FUNCTION SelectPrinter( oWnd )
   LOCAL hDC := PrinterSetup()
   IF hDC != 0
      cPrinter := PrnGetName()
      oWnd:cTitle := cPrinter
      DeleteDC( hDC )
   ENDIF
RETURN NIL

STATIC FUNCTION ShowPreview()
   LOCAL oPrn
   IF Empty( cPrinter )
      MsgInfo( "Selecciona primero una impresora" )
      RETURN NIL
   ENDIF
   PRINT oPrn NAME "PrinterSetup test" TO cPrinter PREVIEW MODAL
      PAGE
         oPrn:Say( 100, 100, "PrinterSetup test" )
      ENDPAGE
   ENDPRINT
RETURN NIL

Ten en cuenta que esto recuerda QUÉ impresora usa el siguiente informe, pero no preselecciona el siguiente PrinterSetup() ni conserva todos los ajustes del driver. Para conservar también eso haría falta guardar una configuración de sesión completa (DEVNAMES/DEVMODE) separada de los recursos de cada trabajo, distinto de cambiar la predeterminada de Windows.
