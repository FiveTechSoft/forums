Anunciando FWH Remote View: Te permite usar tus apps de FWH en la web sin cambiar nada! 💻👁️☁️

https://fivetechsoft.github.io/FWH_docs/en/internet/remoteview.html

Code: Select all Collapse
ACTIVATE WINDOW oWnd ;
      ON INIT ( RemoteViewSetOffset( 200, 200 ), ;
                If( RemoteViewStart( oWnd:hWnd, 8080 ), ;
                    oWnd:SetText( "FWH Remote View - http://localhost:8080" ), ;
                    MsgStop( "No se pudo iniciar Remote View" ) ) ) ;
      VALID ( RemoteViewStop(), .T. )
