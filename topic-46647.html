Estimado Adolfo,

Excelente observación, muchas gracias :idea:

Causa raíz

Al hacer clic en otra pestaña, TFolder:SetOption() oculta la página actual antes de que el GET pierda el foco. Cuando llega el
WM_KILLFOCUS, TControl:KillFocus() (source/classes/control.prg:1214) solo postea FM_LOSTFOCUS (que es quien evalúa el VALID vía
FWLostFocus → lValid()) si la página del control es visible — y ya no lo es. Resultado: TGet:LostFocus() asigna el buffer a la
variable pero el bValid nunca se evalúa.

El fix

En source/classes/folder.prg:1124, TFolder:SetOption() ahora valida el control que tiene el foco en la página activa antes de
cambiar. Es el punto único por el que pasan todos los cambios de página (clic en pestaña, Ctrl+Tab, Alt+tecla, SetOption()
programático):

Code: Select all Collapse
        if nOption > 0 .and. nOption != ::nOption .and. ::nOption > 0 .and. ;
              ::nOption <= Len( ::aDialogs ) .and. ::aDialogs[ ::nOption ] != nil
           oCtrl = ::aDialogs[ ::nOption ]:oCtlFocus
           if oCtrl != nil .and. GetFocus() == oCtrl:hWnd .and. ;
                 __objHasMsg( oCtrl, "lValid" ) .and. ! oCtrl:lValid()
              ::SetCurSel( ::nOption )   // revierte la pestaña
              oCtrl:SetFocus()           // devuelve el foco al GET
              return nil
           endif
        endif

El chequeo GetFocus() == oCtrl:hWnd hace que solo actúe cuando el foco está realmente en el control (caso interactivo), sin
alterar cambios de página programáticos con el foco fuera.
