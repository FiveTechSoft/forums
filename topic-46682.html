CaSqlTools – Cliente de consultas SQL para MariaDB/MySQL (Windows)

Posted: Wed Sep 09, 2026 04:18 AM

Les comparto esta herramienta que venimos desarrollando: CaSqlTools, un cliente de consultas SQL enfocado a MariaDB/MySQL con una interfaz moderna y ligera.
¿Qué incluye?

  • Editor SQL con ejecución rápida (Ctrl+Enter) y resultados en pestañas múltiples, cada una con su propio resultado.
  • Explorador de bases de datos: navega bases y tablas, edita/elimina tablas, crea bases nuevas, renombra, copia el script CREATE y consulta con doble clic.
  • Copias de seguridad y restauración: backup de una base completa o de tablas sueltas, restauración a la misma base o a una nueva, con archivos marcados por fecha/hora.
  • Perfiles de conexión guardados para conectar en un clic (host, puerto, usuario, contraseña, base).
  • Carga de scripts desde archivo .sql y refresco inmediato de la consulta.
  • Panel de mensajes con tiempos de ejecución y errores claros.
    Detalle técnico: usa el motor nativo de base de datos de FiveWin (no tienes que instalar ningún driver adicional; el libmariadb va incluido en el instalador).
    Instalador para Windows 64 bits, 101 MB, se instala en Archivos de programa\CasoftSystem\CaSqlTools con acceso directo en escritorio y menú inicio.
    Descarga directa: https://casoftsystemweb.com/install/CaSqlToolsSetup.exe
    Cualquier duda o sugerencia, por aquí estoy. ¡Saludos!

CaSqlTools Dashboard v0.2.0 — Electron + worker nativo FWH para MariaDB
Comparto la nueva versión de CaSqlTools, nuestro panel de administración para MariaDB que combina una interfaz moderna (HTML/CSS/Javascript con Electron) con el manejador nativo de FiveWin en el backend: el trabajo de base de datos lo hace un worker compilado con Harbour/FWH que se comunica con la UI por línea de comandos (spawn + JSON). Es decir, en la capa de datos sigue siendo 100% FiveWin (maria_Connect, RowSet, Execute, BackUp, Restore).
Novedades de la versión 0.2.0:

  • Editor SQL con resaltado de sintaxis en vivo (palabras clave, funciones, cadenas, números y comentarios), a través de un overlay sincronizado con el scroll.
  • Edición directa de los resultados: haces doble clic en una celda, editas y se genera el UPDATE por la clave primaria automáticamente. También puedes añadir filas (INSERT) y eliminar filas desde el grid (con su confirmación), todo sin escribir una sola línea de SQL.
  • Menú contextual en la grilla: copiar celdas seleccionadas, copiar toda la tabla en formato CSV, exportar a archivo .CSV (con BOM para que abra bien en Excel) y recargar (Requery).
  • Backup y restauración desde el árbol de bases: backup completo de una base, de tablas sueltas, y restauración a la misma base o a una nueva — usando los métodos nativos BackUp() / Restore() de FWH.
  • Perfiles de conexión guardados, listado de bases/tablas, creación/edición/renombrado de bases, diálogos de columnas, copiar CREATE TABLE, pestañas de resultados y panel de mensajes.
  • Instalador para Windows (X64) en Archivos de programa\CasoftSystem\CaSqlTools.
    El worker se compila con el CaSoftSystem Editor y el entorno FWH 26.06 x64; el instalador se puede descargar desde: https://casoftsystemweb.com/install/CaSqlToolsSetup.exe

CaSqlTools Dashboard — v0.3.1 a v0.3.4 (Electron + workers FWH/MariaDB nativos)
Actualización del Dashboard de consultas SQL para MariaDB/MySQL. Interfaz moderna en Electron con la capa de datos en un worker nativo FiveWin (FWH + Harbour MSVC64, conector libmariadb), sin librerías intermedias.
Novedades de esta serie:

  • Edición directa del grid sobre SELECT * FROM tabla con clave única: UPDATE por PK.
  • Filas existentes: todas las columnas editables, incluida la clave primaria (el WHERE usa el valor original, así que el UPDATE persiste correctamente aunque cambies la PK).
  • Filas nuevas (+ Fila): la PK manual se puede escribir; solo la columna auto_increment queda bloqueada (la genera la DB).
  • Eliminar fila con confirmación; la hoja se recarga sola tras INSERT/DELETE.
  • Panel de bases de datos: las tablas ahora se expanden (clic) y muestran sus columnas con tipo, marcador de PRIMARY KEY (🔑 / UNI ◎) y auto_increment (▸auto), en caché para no re-consultar. Clic en una columna carga SELECT \columna\` FROM \`db\`.\`tabla\`` en el editor; doble clic en tabla lo ejecuta. Expandir el árbol ya no ensucia el editor con la consulta.
  • Buscador en resultados: filtra la página actual del grid por cualquier columna, sin tocar la base.
  • Ayuda (?) actualizada como guía rápida dentro de la app.
    Instalador NSIS x64: https://casoftsystemweb.com/install/CaSqlToolsSetup.exe
    Stack: Electron 43 + worker FWH 26.06 (FiveWin nativo, FWCONNECT/RowSet/Execute) compilado con Harbour + MSVC64.
