Kurztasten – Pick a group. Press a key. Get going.

Posted: Thu Nov 12, 2026 04:39 PM

Hi everyone,

We open the same applications, folders and websites every day. Yet we often spend time searching for the right icon, folder or bookmark.

I'd like to introduce Kurztasten, a small Windows launcher that keeps your favorite shortcuts organized and just a few keystrokes away.

How it works

Start Kurztasten and press Ctrl + Alt + Space to open the selection window. Choose a group, then press a number from 1 to 9 to launch the corresponding application, folder or website immediately — no Enter key required. You can also open an item with a double-click.


Note: The images are AI-generated illustrations, not screenshots of the actual application.

10 groups × 9 shortcuts

You can organize up to 90 shortcuts in ten groups — for example, development tools, projects, work folders or frequently used websites.

Keys 1–9 select groups 1–9, while 0 selects group 10. Within the selected group, keys 1–9 launch the individual entries.


Note: The images are AI-generated illustrations, not screenshots of the actual application.

Easy setup with F2

Press F2 to open the setup window. You can name groups, choose their colors, and add, edit, move or remove entries. Changes only take effect when you save them.


Note: The images are AI-generated illustrations, not screenshots of the actual application.

The idea is simple: whether it's your code editor, a project directory or an essential website, the things you use most should always be easy to reach.

Sidekick Becomes Kurztasten – What's New

The previous Windows launcher has been further developed under the name Kurztasten. Compared to Sidekick Basic 0.1, the following features have been added:

  • Groups and more entries: Up to 36 groups with 36 entries each – a total of 1,296 slots. Groups can be named and color-coded.

  • Selection using A–Z and 0–9: Groups and entries can be selected using letters and numbers. Selection keys are case-insensitive; uppercase letters are displayed.

  • Configuration directly within the program: Press F2 to create, edit, move, and delete groups and entries, as well as configure the hotkey used to open the launcher.

  • Encrypted credentials: A username and password can be stored for each entry. These fields are encrypted using AES-256-GCM. A separate master password is required when starting the program.

  • Copying via keyboard: F3 opens the credentials dialog. Ctrl+U copies the username, and Ctrl+P copies the password of the selected entry. Use Ctrl+V to paste.

  • Change the master password at any time: Simply go to F2 → Change Master Password. Using the existing password, all stored credentials are re-encrypted with the new master password. Groups and entries remain unchanged.

  • New manual and video: HTML and PDF documentation with actual screenshots, plus a Windows application demonstration video narrated by a German-speaking female voice. The video starts automatically in muted mode on the manual page; sound can be enabled.

  • Clean distribution package: A ZIP archive containing the program, an empty configuration, and the manual. New users create their own master password when launching the program for the first time.

The familiar keyboard shortcut remains Ctrl+Alt+Space. You can then select the desired group and entry using the keyboard.

Kurztasten – Latest Improvements and New Features

Since the previous feature overview, the following improvements have been added:

  • Dedicated group management (F3)
    Groups now have their own management dialog. F2 remains the main setup screen. The credentials dialog has moved to F4. Ctrl+U and Ctrl+P remain unchanged.

  • Optional group templates
    Choose from 18 hotel-oriented group suggestions or enter your own group name. Templates are loaded from a separate INI file and suggest a selection key and color. Suggested keys are used only when available.

  • Expanded color palette
    Choose from 32 preset colors, including bold dark colors with white text and lighter colors with dark text. A live preview shows the group's appearance before saving.

  • Choose a browser for each website
    Each website entry can use:

  • The Windows default browser

  • Microsoft Edge

  • Google Chrome

  • Mozilla Firefox

  • A custom browser executable

Installed browsers are detected automatically.

  • Optional new browser window
    A checkbox lets you request a new window for an individual website. Supported browsers are Edge, Chrome and Firefox.

    When unchecked, the previous behavior remains: the browser decides whether to use a tab or a window.

    Important: New windows continue to use the browser profile and its existing sign-in.

  • Larger, more readable text
    The launcher and configuration dialogs now use larger text, with adjusted list rows and labels for improved readability.

  • Return to the running launcher
    Launching Kurztasten again now activates the existing instance instead of displaying the usual "already running" message.

    The currently open dialog is retained. No additional application instance is started.

  • Hotkey support during configuration
    Ctrl+Alt+Space can now also bring back an open setup or editing dialog.

    Unsaved input and the current editing context are preserved.

    • Important – After updating

    1. Save any open changes.

    2. Close Kurztasten once using Ctrl+Q.

    3. Restart Kurztasten to load the new version.

    Kurztasten – One keyboard shortcut, instant access to your applications, websites and daily workflows.
