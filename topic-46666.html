El llamado *sonido de explosión* en FiveWin/FWH suele corresponder al beep de error del sistema (equivalente a `MB_ICONHAND`) que se dispara cuando ocurre un fallo de GDI al dibujar el reporte en el contexto de impresión (por ejemplo, columnas que exceden el ancho, fuentes no válidas, etc.).

Para eliminarlo, tienes dos enfoques:

1. **Corregir la causa:** Revisa que los anchos de columna y las coordenadas del reporte no superen los márgenes de la página.
2. **Silenciar el objeto de impresión:** Si el reporte es correcto pero el sonido persiste, puedes crear el objeto `TPrinter` y desactivar su propiedad de sonido antes de pasarlo al `REPORT`.

Ejemplo propio:

Code: Select all Collapse
FUNCTION ImprimeSinSonido()
   LOCAL oReport, oPrint

   oPrint := TPrinter():New()
   oPrint:lSound := .F.   // Desactiva sonidos de impresión

   REPORT oReport TITLE "Mi Reporte" TO PRINTER oPrint
      COLUMN "Campo" => Field->Campo
      // ... más columnas ...
   ENDREPORT

   oReport:End()

RETURN NIL


Si utilizas `REPORT oReport TO PRINTER` directamente sin instanciar `TPrinter`, FiveWin crea uno interno; en ese caso, tras finalizar el reporte, el sonido ya no se emitirá si no hay errores.
