Estimado Miguel Angel,

IsThemeActive() funciona bárbaro porque solo pregunta: detecta si Windows tiene los temas activados, no aplica nada.
La que aplica el theme es Windows solo, y FiveWin ya lo dibuja automáticamente si tu .exe lleva el manifest de controles comunes. Por eso con IsThemeActive()=.T. pero sin manifest sigues viendo clásico.

  1. Consultar
    IsThemeActive() // ¿Windows usa temas?
    IsAppThemed() // ¿mi app puede usarlos? = tiene manifest + Windows con temas
    AppHasManifest() // ¿linkeé el manifest?
    lThemes() // IsAppThemed() .and. IsThemeActive()
    FW_GetThemeMode() // "Light" / "Dark" de Windows 10/11
    En tu .rc:
    1 24 "WindowsXP.Manifest"
  2. Quitar / ajustar por control
    SetWindowTheme( oGet:hWnd, "", "" ) // vuelve a clásico ese control
    oWnd:SetWindowTheme( "", "" )
    FixThemeControls( oDlg:hWnd )
    Útil con fondos oscuros donde el texto themed sale oscuro.
  3. Estilos FiveWin y modo oscuro
    oBtn:lThemed := .T.
    oBtn:SetThemed( .T. )
    Ojo: no existe FW_SetDarkTheme(). Es:
    FW_SetDarkMode( .T. ) // global toda la app
    FW_SetDarkMode( .F. ) // volver a light
    oDlg:SetDarkMode()
    oBar:SetDarkMode()
    oBrw:SetDarkTheme()
    Típico:
    if FW_GetThemeMode() == "Dark"
    FW_SetDarkMode( .T. )
    endif
    En resumen: no hay que "copiar" el theme de Windows, con manifest + IsAppThemed() ya lo tienes aplicado.

Si no tienes .rc, créalo — build_new.bat lo enlaza solo:
build_new.bat compila y linkea %1.res automáticamente si existe %1.rc junto al .prg (samples/build_new.bat:115,194,247 según variante). No necesitas recursos previos.

  1. Crea miapp.rc (mismo nombre que miapp.prg, en la misma carpeta) con esto — copiado de samples/winxp/xplook.rc:3-9:
    #ifdef FLAT
    1 24 "WindowsXP.Manifest"
    #endif
    #ifdef 64
    1 24 "WindowsXP.Manifest64"
    #endif
  2. Copia los manifests a tu carpeta desde samples/winxp/:
  3. WindowsXP.Manifest
  4. WindowsXP.Manifest64
    (O ajusta la ruta en el .rc, p.ej. 1 24 "../WinXP/WindowsXP.Manifest".)
  5. Recompila con tu variante habitual, p.ej. build_new.bat miapp hm64.
  6. Verifica en runtime:
    ? AppHasManifest() // .T. = quedó linkeado
    ? IsAppThemed() // .T. = Windows lo está aplicando
    Alternativa sin .rc: archivo externo miapp.exe.manifest junto al .exe — _HasManifest() también lo detecta (source/internal/themes.c:106-119) — pero el recurso embebido es lo recomendado, no depende de un archivo suelto.
