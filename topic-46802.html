Securing DBF Files without Moving to SQL

Posted: Tue Nov 24, 2026 10:32 AM

The idea is to move the existing Harbour microservice together with the DBF, CDX and FPT files into a separate virtual machine on the same physical server.

  • No mapped drives.
  • No SMB shares.
  • No shared directories.
  • No direct file access from Apache or PHP.
  • Communication exclusively through our existing TCP socket connection using HTTP/JSON.
    The actual DBF processing remains local within the virtual machine.

This gives us a level of data isolation similar to that of a SQL server architecture, without having to change our existing database format or business logic.

The virtual machine effectively acts as a protective envelope around our DBF files. We retain the simplicity of DBF storage while adding a separate security boundary.

The only significant change on the application side would be the destination IP address of the microservice.

SERVERBOOK AIRBAG – A Low-Cost Test Environment Using a Refurbished Notebook

We do not necessarily need new or expensive hardware for our AIRBAG development projects.

Today, I successfully installed Windows Server 2025 on an older HP EliteBook 8470p.

Hardware specifications:

  • Intel Core i7-3520M, 2.90 GHz
  • 16 GB RAM
  • Samsung 256 GB SSD
  • Gigabit Ethernet

These older business notebooks are available at very reasonable prices as refurbished devices. One particular advantage is the excellent accessibility of the hardware. RAM, SSD and wireless modules can easily be replaced or removed.

Requirements and installation:

  • Windows Server 2025 Standard Evaluation (Desktop Experience) is the recommended edition.
  • A bootable UEFI USB stick, created using a tool such as Rufus.
  • Press ESC during startup, followed by F9 to open the boot menu.
  • Select the USB stick in UEFI mode.
  • If necessary, convert the disk from MBR to GPT. Please note that using DiskPart's CLEAN command will erase all existing data.
  • Installation is possible without an Internet connection.

Windows Server 2025 Evaluation is available free of charge for 180 days. Initial online activation is required within ten days.

Potential areas of experimentation:

  • Hyper-V and virtual machines
  • DBF file isolation and protection
  • Harbour microservices
  • AppLocker and group policies
  • BitLocker and data security
  • Backup and disaster recovery
  • Reducing the hardware attack surface, for example by physically removing the WLAN module

The main advantage is that we can experiment independently of our production systems and deliberately simulate failures and recovery scenarios without affecting daily operations.

The installation was successful, and Windows recognized the essential hardware components. Long-term stability still needs to be tested.

With a very small investment, we can set up our own SERVERBOOK AIRBAG test laboratory.
