Dear Shridhar,

For a CLI-based OCR (Image to Text) solution, **Tesseract OCR** is the standard open-source tool. It handles JPEG/PNG and can be easily invoked from a Harbour/FWH application.

Tesseract does not output JSON natively (it creates plain text or TSV), but you can capture its output and encode it to JSON directly in your code. Minimal example (own code, not proprietary):

Code: Select all Collapse
FUNCTION OCR2JSON( cImage )
   LOCAL cBase := "ocr_out"
   // Calls: tesseract image.png ocr_out
   hb_run( "tesseract " + cImage + " " + cBase + " --psm 6" )
   RETURN hb_jsonEncode( { "file" => cImage, "content" => hb_memoread( cBase + ".txt" ) } )


Compile your Harbour app linking the `hbjson` library (`-lhbjson`). This gives you a JSON string/result as requested.
