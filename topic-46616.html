Añadiendo:

Para asegurarse de que su aplicación se visualice correctamente con la interfaz de usuario actualizada y las esquinas redondeadas de Windows 11, puede añadir la etiqueta <windowsSettings> para habilitar el escalado de PPP (DPI) por monitor y la compatibilidad con rutas de archivo largas:

Code: Select all Collapse
<application xmlns="urn:schemas-microsoft-com:asm.v3">
    <windowsSettings>
        <dpiAwareness xmlns="http://microsoft.com">PerMonitorV2, PerMonitor</dpiAwareness>
        <dpiAware xmlns="http://microsoft.com">true</dpiAwareness>
        <longPathAware xmlns="http://microsoft.com">true</longPathAware>
    </windowsSettings>
</application>
