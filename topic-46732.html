Dear Jimmy,

The error comes from mixing two different moments:

  • #define, #ifdef, #endif are preprocessor commands. They are processed before the compilation, when the program does not exist yet. So a PUBLIC variable (which only exists when the program runs) can never decide a #define.
  • IF ... ENDIF is executed at runtime.

So you have two options, depending on what you need:

1) Decide at compile time (what you asked in your other thread): pass the symbol to the compiler with /dFULLAPP and use:

Code: Select all Collapse
#ifdef FULLAPP
   // code only for the full version
#endif

2) Decide at runtime: test the variable with a function, not with #define. For example:

Code: Select all Collapse
PUBLIC FULLAPP := .T.      // somewhere at the start, if it is the full version

IF Type( "FULLAPP" ) != "U" .AND. FULLAPP
   // full version code
ELSE
   // standalone code
ENDIF

Type( "FULLAPP" ) returns "U" if the variable does not exist, so there is no error. Harbour also has __mvExist( "FULLAPP" ) for the same purpose. Both are from memory and I have not tested them here, please try them.
