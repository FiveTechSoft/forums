Nombre del usuario en Windows: GetUserName y los formatos de GetUserNameEx

En un ejemplo anterior de esta serie vimos cómo obtener el nombre del equipo (GetComputerNameEx). Este es el complemento natural: el nombre del USUARIO que ejecuta el programa. GetUserName devuelve el nombre de inicio de sesión y GetUserNameEx lo devuelve en varios formatos de directorio. No hemos encontrado un ejemplo previo dedicado a GetUserNameEx en estos foros (si lo hay, agradecemos la referencia); en cualquier caso, aquí va uno integrado y validado.

Qué hace el programa

Al pulsar "Consultar ahora" muestra, del equipo donde se ejecuta:

  • GetUserName (advapi32): el nombre de inicio de sesión. Microsoft documenta que si el hilo está impersonando a un cliente, devuelve el nombre de ese cliente.
  • GetUserNameEx (secur32) en siete formatos de la enumeración documentada EXTENDED_NAME_FORMAT: FQDN (1), SamCompatible (2), Display (3), UniqueId GUID (6), Canonical (7), UserPrincipal (8) y DnsDomain (12).
  • Cada fila muestra su resultado real: el valor o el código de GetLastError con su nombre documentado.

La enumeración tiene más formatos (CanonicalEx, ServicePrincipal, GivenName, Surname...); Microsoft documenta que GivenName y Surname solo están disponibles para usuarios de Active Directory.

El límite documentado que hace interesante el ejemplo

Microsoft documenta que si la cuenta NO es de dominio, solo NameSamCompatible está soportado. Los demás formatos pueden fallar con errores documentados: ERROR_NONE_MAPPED (1332, el nombre no está disponible en ese formato) o ERROR_NO_SUCH_DOMAIN (1355, el controlador de dominio no está disponible). También está documentado el caso ERROR_MORE_DATA (234): si el buffer es pequeño, nSize recibe el tamaño necesario, en caracteres Unicode incluso en la variante ANSI; el programa reintenta una vez con ese tamaño antes de dar el error.

Resultados medidos

Programa compilado con Harbour 3.2.1dev y FWH oficial (cabeceras del entorno con versión declarada 26.10), ejecutado en Wine 11.19 (sin Windows nativo) con un usuario de pruebas sin dominio. Los valores se midieron el 23 de noviembre de 2026 y se repitieron con idéntico resultado el 25 de noviembre en una segunda sesión del entorno oficial:

  • GetUserName (clásico): "sandbox" (el usuario de la prueba).
  • SamCompatible (2): "E2B\sandbox", es decir, EQUIPO\usuario, el formato documentado para cuentas sin dominio.
  • Los otros seis formatos (FQDN, Display, UniqueId, Canonical, UserPrincipal, DnsDomain): error 1332 (ERROR_NONE_MAPPED), coherente con el límite documentado: sin dominio solo SamCompatible está soportado.
  • El resumen final lo dice tal cual: "Clasico: ok. Formatos Ex: 1 respondidos, 6 con error documentado".
  • Pulsar de nuevo limpia las filas y repite la medición con el mismo resultado; en esta prueba la ventana se cerró y el proceso terminó.

Lo que NO hemos probado: un entorno con dominio (qué formatos responden ahí dependerá de la información disponible en cada caso y de lo que documenta Microsoft; no lo afirmamos), la impersonación, ni el caso ERROR_MORE_DATA. Estos valores son los medidos en esas dos ejecuciones Wine; no afirmamos que Windows nativo responda igual en cada formato.

Requisitos

Mínimo documentado de estas APIs: Windows 2000 Professional. GetUserName vive en advapi32, que una aplicación Windows ya enlaza habitualmente; GetUserNameEx vive en secur32 y hay que añadir Secur32.lib al enlace. Es el mínimo documentado de estas APIs, no una garantía de compatibilidad de toda la aplicación de ejemplo.

//----------------------------------------------------------------------------//
// NOMBREUSUARIO.PRG (v1)
// Nombre del usuario: GetUserName y los formatos de GetUserNameEx
// Ejemplo didactico FiveWin (FWH) + Harbour
//
// Que muestra:
//   - GetUserName (advapi32) devuelve el nombre de inicio de sesion
//     del usuario que ejecuta el programa; si el hilo esta
//     impersonando a un cliente, devuelve el nombre de ese cliente
//     (doc. Microsoft)
//   - GetUserNameEx (secur32) devuelve ese mismo nombre en varios
//     formatos de directorio: FQDN, SamCompatible (EQUIPO\usuario),
//     Display, UniqueId (GUID), Canonical, UserPrincipal y
//     DnsDomain (doc. Microsoft)
//   - Limite documentado central: si la cuenta NO es de dominio,
//     solo NameSamCompatible esta soportado; los demas formatos
//     fallan con errores documentados como ERROR_NONE_MAPPED (1332,
//     el nombre no esta disponible en ese formato) o
//     ERROR_NO_SUCH_DOMAIN (1355, no hay controlador de dominio)
//   - Comportamiento de buffer documentado: si el buffer es
//     pequeno, la funcion falla con ERROR_MORE_DATA (234) y nSize
//     recibe el tamaño necesario, en caracteres Unicode incluso en
//     la variante ANSI; aqui se reintenta una vez con ese tamaño
//     antes de dar el error por bueno
//   - El ejemplo prueba cada formato y muestra por fila el valor
//     real o su codigo de error: en un equipo sin dominio lo normal
//     es que solo respondan GetUserName y SamCompatible
//
// Este programa usa las variantes ANSI de las APIs (GetUserNameA /
// GetUserNameExA), coherentes con una aplicacion Harbour ANSI.
//
// Minimo documentado de estas APIs: Windows 2000 Professional
// (doc. Microsoft). GetUserName vive en advapi32 y GetUserNameEx
// en secur32; ambas son bibliotecas habituales de Windows, pero
// secur32 hay que enlazarla de forma explicita.
//
// Comportamiento ante errores:
//   - Cada fila muestra su resultado real: valor o codigo de
//     GetLastError con su nombre documentado cuando lo hay
//   - Al pulsar de nuevo se limpian todas las filas: nada de valores
//     de la ejecucion anterior
//   - El estado final resume cuantos formatos respondieron de
//     verdad; un error documentado no es un fallo del programa,
//     es informacion del entorno (equipo sin dominio, etc.)
//
// Documentacion de Microsoft:
//   https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-getusernamea
//   https://learn.microsoft.com/en-us/windows/win32/api/secext/nf-secext-getusernameexa
//   https://learn.microsoft.com/en-us/windows/win32/api/secext/ne-secext-extended_name_format
//----------------------------------------------------------------------------//

#include "FiveWin.ch"

static oSayClasico, oSayFqdn, oSaySam, oSayDisplay, oSayGuid
static oSayCanon, oSayUpn, oSayDns
static oSayEstado

//----------------------------------------------------------------------------//

function Main()

   local oWnd

   oWnd := TWindow():New( 0, 0, 400, 600, ;
      "Nombre del usuario: GetUserName y formatos Ex", , , , , , , , , , , , ;
      .t., .t., .t., .t., .t. )

   @ 15, 15 SAY "GetUserName devuelve el nombre de inicio de sesion y GetUserNameEx" OF oWnd SIZE 570, 15 PIXEL

   @ 33, 15 SAY "lo da en distintos formatos de directorio. Fuera de un dominio," OF oWnd SIZE 570, 15 PIXEL

   @ 51, 15 SAY "Microsoft documenta que solo NameSamCompatible esta soportado." OF oWnd SIZE 570, 15 PIXEL

   @ 84, 220 BUTTON "Consultar ahora" OF oWnd ;
      SIZE 160, 26 PIXEL ACTION BtnConsulta()

   @ 124, 15 SAY "GetUserName (clasico):" OF oWnd SIZE 200, 18 PIXEL
   @ 124, 220 SAY oSayClasico PROMPT "" OF oWnd SIZE 365, 18 PIXEL

   @ 146, 15 SAY "FQDN (1):" OF oWnd SIZE 200, 18 PIXEL
   @ 146, 220 SAY oSayFqdn PROMPT "" OF oWnd SIZE 365, 18 PIXEL

   @ 168, 15 SAY "SamCompatible (2):" OF oWnd SIZE 200, 18 PIXEL
   @ 168, 220 SAY oSaySam PROMPT "" OF oWnd SIZE 365, 18 PIXEL

   @ 190, 15 SAY "Display (3):" OF oWnd SIZE 200, 18 PIXEL
   @ 190, 220 SAY oSayDisplay PROMPT "" OF oWnd SIZE 365, 18 PIXEL

   @ 212, 15 SAY "UniqueId GUID (6):" OF oWnd SIZE 200, 18 PIXEL
   @ 212, 220 SAY oSayGuid PROMPT "" OF oWnd SIZE 365, 18 PIXEL

   @ 234, 15 SAY "Canonical (7):" OF oWnd SIZE 200, 18 PIXEL
   @ 234, 220 SAY oSayCanon PROMPT "" OF oWnd SIZE 365, 18 PIXEL

   @ 256, 15 SAY "UserPrincipal (8):" OF oWnd SIZE 200, 18 PIXEL
   @ 256, 220 SAY oSayUpn PROMPT "" OF oWnd SIZE 365, 18 PIXEL

   @ 278, 15 SAY "DnsDomain (12):" OF oWnd SIZE 200, 18 PIXEL
   @ 278, 220 SAY oSayDns PROMPT "" OF oWnd SIZE 365, 18 PIXEL

   @ 308, 15 SAY oSayEstado PROMPT "Pulsa Consultar ahora para ver los datos de este equipo." OF oWnd SIZE 570, 18 PIXEL

   @ 338, 250 BUTTON "Cerrar" OF oWnd ;
      SIZE 100, 26 PIXEL ACTION oWnd:End()

   ACTIVATE WINDOW oWnd CENTERED

return nil

//----------------------------------------------------------------------------//

static function BtnConsulta()

   local cNombre
   local aFmt
   local nOk := 0, nErr := 0
   local i, c

   // Limpiar resultados de la ejecucion anterior
   oSayClasico:SetText( "" )
   oSayFqdn:SetText( "" )
   oSaySam:SetText( "" )
   oSayDisplay:SetText( "" )
   oSayGuid:SetText( "" )
   oSayCanon:SetText( "" )
   oSayUpn:SetText( "" )
   oSayDns:SetText( "" )
   oSayEstado:SetText( "Consultando..." )

   // GetUserName clasico (advapi32)
   cNombre := UN_Clasico()

   if cNombre == NIL
      oSayClasico:SetText( DescError( UN_LastError() ) )
   else
      oSayClasico:SetText( cNombre )
   endif

   // Formatos de GetUserNameEx (secur32); valores numericos segun
   // la enumeracion documentada EXTENDED_NAME_FORMAT
   aFmt := { { oSayFqdn,    1 }, ;   // NameFullyQualifiedDN
             { oSaySam,     2 }, ;   // NameSamCompatible
             { oSayDisplay, 3 }, ;   // NameDisplay
             { oSayGuid,    6 }, ;   // NameUniqueId
             { oSayCanon,   7 }, ;   // NameCanonical
             { oSayUpn,     8 }, ;   // NameUserPrincipal
             { oSayDns,    12 }  }   // NameDnsDomain

   for i := 1 to Len( aFmt )
      c := UN_Formato( aFmt[ i ][ 2 ] )
      if c == NIL
         aFmt[ i ][ 1 ]:SetText( DescError( UN_LastError() ) )
         nErr++
      else
         aFmt[ i ][ 1 ]:SetText( iif( Empty( c ), "(vacio)", c ) )
         nOk++
      endif
   next

   // Estado final segun el resultado real de cada fila
   oSayEstado:SetText( "Clasico: " + ;
      iif( cNombre == NIL, "error", "ok" ) + ;
      ". Formatos Ex: " + AllTrim( Str( nOk ) ) + " respondidos, " + ;
      AllTrim( Str( nErr ) ) + " con error documentado" )

return nil

//----------------------------------------------------------------------------//
// Codigo de error con su nombre documentado cuando lo hay

static function DescError( nErr )

   local c

   do case
      case nErr == 1332
         c := "(1332: ERROR_NONE_MAPPED, sin formato disponible)"
      case nErr == 1355
         c := "(1355: ERROR_NO_SUCH_DOMAIN)"
      case nErr == 234
         c := "(234: ERROR_MORE_DATA)"
      case nErr == 87
         c := "(87: ERROR_INVALID_PARAMETER)"
      otherwise
         c := "(error " + AllTrim( Str( nErr ) ) + ")"
   endcase

return c

//----------------------------------------------------------------------------//

#pragma BEGINDUMP

#include <windows.h>
#include <lmcons.h>          // UNLEN
#define SECURITY_WIN32
#include <security.h>        // secext.h: GetUserNameExA, EXTENDED_NAME_FORMAT
#include "hbapi.h"

// Ultimo GetLastError() de las UN_*
static DWORD s_dwLastError = 0;

// UN_Clasico() -> cNombre o NIL
// GetUserNameA: buffer de UNLEN+1 basta para cualquier nombre de
// inicio de sesion (doc. Microsoft). En nSize devuelve los
// caracteres copiados INCLUYENDO el nulo final.
HB_FUNC( UN_CLASICO )
{
   char szBuf[ UNLEN + 1 ];
   DWORD nSize = sizeof( szBuf );

   if( ! GetUserNameA( szBuf, &nSize ) )
   {
      s_dwLastError = GetLastError();
      hb_ret();   // NIL
      return;
   }

   hb_retc( szBuf );
   s_dwLastError = 0;
}

// UN_Formato( nFormato ) -> cNombre o NIL
// GetUserNameExA con un formato de EXTENDED_NAME_FORMAT.
// Si el buffer es pequeno falla con ERROR_MORE_DATA y nSize recibe
// el tamaño necesario en caracteres Unicode incluso en la variante
// ANSI (doc. Microsoft); se reintenta una vez con ese tamaño
// antes de informar del error.
HB_FUNC( UN_FORMATO )
{
   EXTENDED_NAME_FORMAT nFmt = ( EXTENDED_NAME_FORMAT ) hb_parni( 1 );
   static char szBuf[ 4096 ];
   ULONG nSize = sizeof( szBuf );

   if( GetUserNameExA( nFmt, szBuf, &nSize ) )
   {
      hb_retc( szBuf );
      s_dwLastError = 0;
      return;
   }

   s_dwLastError = GetLastError();

   if( s_dwLastError == ERROR_MORE_DATA )
   {
      // nSize: tamaño necesario en caracteres Unicode; se pide el
      // doble en bytes ANSI por margen, con tope en el buffer
      ULONG nBytes = nSize * 2 + 8;

  if( nBytes <= sizeof( szBuf ) )
  {
     ULONG nSize2 = sizeof( szBuf );

     if( GetUserNameExA( nFmt, szBuf, &nSize2 ) )
     {
        hb_retc( szBuf );
        s_dwLastError = 0;
        return;
     }
     s_dwLastError = GetLastError();
  }
   }

   hb_ret();   // NIL; el codigo queda en UN_LastError()
}

// UN_LastError() -> ultimo GetLastError() de las UN_*
HB_FUNC( UN_LASTERROR )
{
   hb_retnl( ( long ) s_dwLastError );
}

#pragma ENDDUMP

//----------------------------------------------------------------------------//
