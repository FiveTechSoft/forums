array to Excel

Posted: Tue Jun 16, 2026 03:55 PM

Necesito pasar un array 2D a Excel.
Al ejecutar este test, no se copia nada en el excel.

Code: Select all Collapse
PROCEDURE TestMatriz()
   LOCAL oExcel, oWorkbook, oSheet
   LOCAL aDatos := {}

   oExcel := CreateObject( "Excel.Application" )
   oExcel:Visible := .T.
   oWorkbook := oExcel:Workbooks:Add()
   oSheet    := oExcel:ActiveSheet

   aDatos := { ;
      { "Producto A", 120.50, 10 }, ;
      { "Producto B",  85.00, 22 }, ;
      { "Producto C",  45.15, 15 }  ;
      }

   oRange := oSheet:Range( "A1:C3" )
   oRange:Value := aDatos
   

RETURN

Si funciona esto:

Code: Select all Collapse
oRange:Value := aDatos[1]

Pero ejecutarlo en un loop no es eficiente para arrays grandes, como es mi caso.

Consultando con la IA me responde:

En las versiones recientes de FiveWin para Harbour (no xHarbour), Antonio Linares añadió soporte para escribir arrays completos mediante SAFEARRAY COM. Sin embargo, en xHarbour 123_10120 ese soporte suele ser limitado o inexistente.

Por eso, aunque encuentres ejemplos en Internet como:

oRange:Value := aMatrix

muchos funcionan en Harbour puro y no necesariamente en xHarbour.
...
...
El problema es que ni xHarbour ni FiveWin exponen públicamente una función tipo ArrayToVariant() para matrices 2D, pero sí puedes construir el SAFEARRAY mediante:

SafeArrayCreate()
SafeArrayPutElement()
VariantInit()

y luego pasarlo como VARIANT al objeto COM.

Antonio, me das alguna pista sobre los SAFEARRAY ?

Estimado Ralph,

Hazlo asi:

Code: Select all Collapse
PROCEDURE TestMatriz()  

   LOCAL oExcel, oWorkbook, oSheet, oRange  

   LOCAL aDatos := { ;  

      { "Producto A", 120.50, 10 }, ;  

      { "Producto B",  85.00, 22 }, ;  

      { "Producto C",  45.15, 15 }  ;  

      }  

   LOCAL n  
  

   oExcel    := CreateObject( "Excel.Application" )  

   oExcel:Visible := .T.  

   oWorkbook := oExcel:Workbooks:Add()  

   oSheet    := oExcel:ActiveSheet  
  

   oExcel:ScreenUpdating := .F.  

   oRange := oSheet:Range( oSheet:Columns( 1 ), oSheet:Columns( Len( aDatos[1] ) ) )  

   for n := 1 to Len( aDatos )  

      oRange:Rows( n ):Value := aDatos[ n ]  

   next  

   oExcel:ScreenUpdating := .T.  
  

RETURN

#include "FiveWin.ch"

PROCEDURE TestMatriz()
  

   LOCAL oExcel, oWorkbook, oSheet, oRange, oBook
   LOCAL aDatos := { ;  

      { "Producto A" , 120.50, 10 }, ;
      { "Producto B",  85.00, 22 }, ;
      { "Producto C",  45.15, 15 }  ;
      }  

   LOCAL n

   oExcel:Visible := .T.

   oWorkbook := oExcel:Workbooks:Add()
   oSheet    := oExcel:ActiveSheet

   oExcel:ScreenUpdating := .F.

   oRange := oSheet:Range( oSheet:Columns( 1 ), oSheet:Columns( Len( aDatos[1] ) ) )

   for n := 1 to Len( aDatos )

  oRange:Rows( n ):Value := aDatos[ n ]

   next

   oSheet:Columns( "A" ):ColumnWidth := 12

   oSheet:Cells( 1, 2 ):Font:Bold := .T.
